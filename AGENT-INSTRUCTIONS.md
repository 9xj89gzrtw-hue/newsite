## 🔑 Key Decisions Already Made (Follow These):

### Typography (from analysis of 23 sites):
- **Primary Font:** Poppins (modern, geometric) — for headings
- **Secondary Font:** Montserrat (elegant) — for body text  
- **Fallback:** system-ui, -apple-system, sans-serif

### Color Palette (recommended):
- Primary: Deep charcoal/navy (#1a1a2e or similar)
- Accent: Warm gold/champagne (#d4af37 or similar)
- Background: Clean white (#ffffff)
- Text: Dark gray (#333333)

### Menu Structure (proven from 23 sites):
```
1. Appetizers/Hors d'Oeuvres (Закуски)
2. Soups/Salads (Супы/Салаты)  
3. Main Courses (Горячие блюда)
   - Chicken/Poultry
   - Beef/Lamb
   - Seafood
   - Vegetarian
4. Sides/Garnishes (Гарниры)
5. Desserts (Десерты)
6. Beverages (Напитки)
```

### Package Tiers (for Russian market):
| Tier | Price Range (₽/person) | Positioning |
|------|------------------------|-------------|
| Классик | 7,000 - 12,000 | Essential elegance |
| Премиум | 12,000 - 20,000 | Elevated experience |
| Делюкс | 20,000 - 35,000 | Luxury touches |

### Dietary Labels (use these abbreviations):
- **ГБ** = Gluten-Free (Без глютена)
- **В** = Vegetarian (Вегетарианское)
- **ВГ** = Vegan (Веганское)
- **БМ** = Dairy-Free (Без молока)
- **О** = Nut-Free (Без орехов)
