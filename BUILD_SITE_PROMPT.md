8. **Сначала эталон → потом своя реализация** (`docs/RULES.md` §2). Каждый
   экран — с разобранного эталона.
9. **`lint` + `typecheck` + `next build` зелёные** перед каждым коммитом.
10. **Agent Browser** на `/` — обязательная верификация перед отчётом.

## 5. Структура сайта (одна страница `/`, секции)

> Порядок секций выверен под сторителлинг и конверсию в калькулятор. Каждая
> секция — `<section>` с `id` для якорной навигации из шапки.

```
/ (single page)
├─ #home        Hero — фоновое видео (Mux, autoplay muted loop) + serif-логотип
├─ #about       О компании — короткий сторителлинг, цифры (лет на рынке, событий)
├─ #menu        Меню — 7 типов в интерактивной сетке/табах с фото
├─ #services    Услуги — 11 карточек с hover-раскрытием
├─ #events      События — masonry фото+видео реальных мероприятий
├─ #calculator  ★ Интерактивный калькулятор стоимости (см. §6)
├─ #testimonials Отзывы — карусель + видео-отзывы
├─ #contact     Контакты — телефон/WhatsApp/Instagram + мини-форма лида
└─ footer       Sticky — копирайт, соцсети, быстрый звонок
```

Шапка (fixed, прозрачная → solidity на скролле): логотип · якоря
(Меню / Услуги / События / Калькулятор / Отзывы / Контакты) · кнопка
«Рассчитать» → скролл к `#calculator` · телефон.

## 6. ★ Интерактивный калькулятор стоимости (детальная спецификация)

> Главная новая функциональность. Должен быть быстрым, живым, прозрачным.

### 6.1. UX
- **Одна панель**, без многошаговых визардов. Все контролы видны одновременно.
- Живой пересчёт итога при любом изменении (debounce 150ms).
- Итог — крупная анимированная цифра (count-up при изменении).
- Кнопка «Оставить заявку с этой сметой» → предзаполняет форму `#contact`
  параметрами + скроллит к ней.
- Адаптив: на мобиле — вертикальный стек, на десктопе — 2 колонки (вводы
  слева, смета справа sticky).

### 6.2. Вводы
1. **Тип мероприятия** (select / карточки): Фуршет / Банкет / Кофе-брейк /
   Доставка закусок / Вегетарианское / Барбекю / Обеды в офис.
2. **Кол-во гостей** (slider 10–500, default 50) с +/- степпером.
3. **Доп. услуги** (checkboxes, multi-select из §3.2):
   - Аренда оборудования
   - Оформление зала
   - Торты на заказ
   - Пирамиды из шампанского
   - Шоколадный фонтан
   - Выездная регистрация
   - Флористическое сопровождение (бесплатно при свадьбе — акция)
4. **Дата** (date input, опционально) — если «сезон свадеб» (май–сентябрь,
   декабрь) → +15% к банкету.

### 6.3. Формула (рубли, рыночные СПб 2026)

```
basePerGuest = PRICE_TABLE[eventType]        // руб/чел
subtotal     = basePerGuest * guests
addonsTotal  = sum(ADDON_PRICE[a] for a in selectedAddons)   // фикс. руб
seasonMult   = isHighSeason(date) ? 1.15 : 1.0
total        = (subtotal + addonsTotal) * seasonMult
perGuest     = total / guests
```

### 6.4. Таблица цен (рыночные СПб, 2026) — вынести в `src/lib/pricing.ts`


## 7. Медиа — откуда брать и как хостить

> Заказчик разрешил копировать фото/видео с эталонных сайтов. Технически —
> скачиваем и пере-хостим через наш стек (никаких горячих ссылок).

### 7.1. Видео
1. Найти подходящие видео-фрагменты на эталонах (hero-loops приготовления,
   сервировки, фуршетов, барбекю).
2. Скачать (curl/ytdl).
3. **Загрузить в Mux** (`@mux/mux-uploader-react` или серверный upload через
   `MUX_TOKEN_*`) → получить `playbackId`.
4. Рендерить через `<VideoPlayer source={{ provider: "mux", playbackId }} />`.
5. Постеры — `muxPoster(playbackId)` (бесплатный thumbnail-эндпоинт Mux).

> Альтернатива для генерации уникальных видео-фонов — **Video-Generation
> скилл** (если нужно что-то, чего нет у эталонов).

### 7.2. Фото
1. Скрапить фото с эталонов (`page_reader` → вытащить `<img src>`).
2. Оптимизировать локально (`sharp`) → AVIF/WebP + blur-DataURL.
3. Хостить в `public/media/` (фото — можно; `.mp4` — нельзя).
4. Рендерить через `<SmartImage alt="..." blurDataURL=... />`.

> Для недостающих фото — **image-search** (реальные фото блюд/сервировки) или
> **image-generation** (кастомные для конкретных меню).

### 7.3. Минимальный набор медиа для запуска
- 1 hero video (фуршет/сервировка) — Mux.
- 7 фото для типов меню (по 1 на тип).
- 11 иконок/мини-фото для услуг (или Lucide-иконки).
- 12–16 фото/видео для галереи событий.
- 2–3 видео-отзыва (или плейсхолдеры).
- 1 фоновое фото для #about (команда/повара).
