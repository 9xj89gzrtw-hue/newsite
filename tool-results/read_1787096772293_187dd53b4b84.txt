    56→## 5. Жёсткие правила (не нарушать)
    57→
    58→1. **Сначала веб-поиск** — подтверждать версии/паттерны актуальным источником
    59→   (≤ 6 мес). Не брать «по памяти».
    60→2. **Сначала эталон** — каждый экран начинается с 3–5 эталонов (Awwwards,
    61→   Dribbble, кейтеринг-каталоги), разбирается через VLM/web-reader,
    62→   воспроизводится 1-в-1 со своим контентом.
    63→3. **Видео — только через Mux/Cloudflare Stream.** Никогда не класть `.mp4` в
    64→   `public/`. Использовать `<VideoPlayer>`.
    65→4. **Фото — только `<SmartImage>`** (обязателен `alt`, blur-плейсхолдер).
    66→   Никаких сырых `<img>`.
    67→5. **Анимация — `transform`/`opacity` only.** Уважать `prefers-reduced-motion`.
    68→6. **Server Components по умолчанию.** `'use client'` и динамические импорты —
    69→   только где нужны.
    70→7. **Доступность обязательна** (семантика, ARIA, контраст AA, фокус, 44px
    71→   touch-target).
    72→8. **Sticky footer** (`min-h-screen flex flex-col` + `mt-auto`).
    73→9. **Без индиго/синего.** Палитра — OKLCH-токены (cream/espresso/terracotta/
    74→   sage/honey).
    75→10. **Коммиты — Conventional Commits** (`feat:`, `fix:`, `docs:` …).
    76→11. **Перед коммитом:** `lint` + `typecheck` зелёные, `design-review` пройден.
    77→12. **Деплой — авто из `main`.** Никаких ручных выкаток.

   350→### Грабли (зафиксировать для будущего)
   351→
   352→1. **`body { overflow-x: hidden }` ломает `position: sticky`** — создаваемый
   353→   scroll-container делает sticky относительно себя, а не viewport. Слово
   354→   уезжало на -626px. **Решение: `overflow-x: clip`** (поддержка 2024+).
   355→2. **framer-motion НЕ применяет `clipPath` как string MotionValue** —
   356→   `style={{ clipPath: wordClip }}` где `wordClip = useTransform(..., [str,str])`
   357→   рендерит `clipPath: none` в DOM. Motion-values `opacity`/`scale`/`y`/`x`
   358→   работают, а `clipPath` string — нет. **Решение: SVG `<clipPath>`** или
   359→   императивный `useMotionValueEvent` + `ref.style.clipPath = ...`.
   360→3. **CSS `background-clip: text` + framer-motion `style` с motion-values**
   361→   ненадёжно — static-стили (backgroundImage, bg-clip) могут теряться при
   362→   смешивании с motion-values в одном `style`-объекте. **Решение: SVG** для
   363→   text-as-window, либо static-стили выносить в className/CSS-класс, motion —
   364→   на обёртку.
   365→4. **`useTransform` с `backgroundColor` hex-string interpolation** — применялся
   366→   к DOM как interpolated цвет, но давал серый `rgb(114,109,104)` вместо
   367→   charcoal `#1A1614` при scrollYProgress=0. **Решение: stacked opacity divs**
   368→   (charcoal base + cream overlay с opacity) — надёжнее color-interpolation.
   369→5. **Dev-сервер в песочнице умирает на границе tool-call** — sandbox убивает
   370→   процессную группу bash-команды. **Решение: dev + agent-browser в ОДНОМ
   371→   bash-вызове** (одна process group). `setsid bash -c 'exec next dev' &` не
   372→   помогает — умирает всё равно при возврате tool.
   373→6. **agent-browser не достучался до localhost:3000 из своего sandbox** в
   374→   отдельном вызове — ERR_CONNECTION_REFUSED. Работает только когда dev-сервер
   375→   запущен в ТОМ ЖЕ bash-вызове, что и `agent-browser open`.
