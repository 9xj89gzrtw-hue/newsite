    53→## 5. Жёсткие правила (не нарушать)
    54→
    55→1. **Сначала веб-поиск** — подтверждать версии/паттерны актуальным источником
    56→   (≤ 6 мес). Не брать «по памяти».
    57→2. **Сначала эталон** — каждый экран начинается с 3–5 эталонов (Awwwards,
    58→   Dribbble, кейтеринг-каталоги), разбирается через VLM/web-reader,
    59→   воспроизводится 1-в-1 со своим контентом.
    60→3. **Видео — только через Mux/Cloudflare Stream.** Никогда не класть `.mp4` в
    61→   `public/`. Использовать `<VideoPlayer>`.
    62→4. **Фото — только `<SmartImage>`** (обязателен `alt`, blur-плейсхолдер).
    63→   Никаких сырых `<img>`.
    64→5. **Анимация — `transform`/`opacity` only.** Уважать `prefers-reduced-motion`.
    65→6. **Server Components по умолчанию.** `'use client'` и динамические импорты —
    66→   только где нужны.
    67→7. **Доступность обязательна** (семантика, ARIA, контраст AA, фокус, 44px
    68→   touch-target).
    69→8. **Sticky footer** (`min-h-screen flex flex-col` + `mt-auto`).
    70→9. **Без индиго/синего.** Палитра — OKLCH-токены (cream/espresso/terracotta/
    71→   sage/honey).
    72→10. **Коммиты — Conventional Commits** (`feat:`, `fix:`, `docs:` …).
    73→11. **Перед коммитом:** `lint` + `typecheck` зелёные, `design-review` пройден.
    74→12. **Деплой — авто из `main`.** Никаких ручных выкаток.

   340→### Грабли (зафиксировать для будущего)
   341→
   342→1. **`body { overflow-x: hidden }` ломает `position: sticky`** — создаваемый
   343→   scroll-container делает sticky относительно себя, а не viewport. Слово
   344→   уезжало на -626px. **Решение: `overflow-x: clip`** (поддержка 2024+).
   345→2. **framer-motion НЕ применяет `clipPath` как string MotionValue** —
   346→   `style={{ clipPath: wordClip }}` где `wordClip = useTransform(..., [str,str])`
   347→   рендерит `clipPath: none` в DOM. Motion-values `opacity`/`scale`/`y`/`x`
   348→   работают, а `clipPath` string — нет. **Решение: SVG `<clipPath>`** или
   349→   императивный `useMotionValueEvent` + `ref.style.clipPath = ...`.
   350→3. **CSS `background-clip: text` + framer-motion `style` с motion-values**
   351→   ненадёжно — static-стили (backgroundImage, bg-clip) могут теряться при
   352→   смешивании с motion-values в одном `style`-объекте. **Решение: SVG** для
   353→   text-as-window, либо static-стили выносить в className/CSS-класс, motion —
   354→   на обёртку.
   355→4. **`useTransform` с `backgroundColor` hex-string interpolation** — применялся
   356→   к DOM как interpolated цвет, но давал серый `rgb(114,109,104)` вместо
   357→   charcoal `#1A1614` при scrollYProgress=0. **Решение: stacked opacity divs**
   358→   (charcoal base + cream overlay с opacity) — надёжнее color-interpolation.
   359→5. **Dev-сервер в песочнице умирает на границе tool-call** — sandbox убивает
   360→   процессную группу bash-команды. **Решение: dev + agent-browser в ОДНОМ
   361→   bash-вызове** (одна process group). `setsid bash -c 'exec next dev' &` не
   362→   помогает — умирает всё равно при возврате tool.
   363→6. **agent-browser не достучался до localhost:3000 из своего sandbox** в
   364→   отдельном вызове — ERR_CONNECTION_REFUSED. Работает только когда dev-сервер
   365→   запущен в ТОМ ЖЕ bash-вызове, что и `agent-browser open`.
