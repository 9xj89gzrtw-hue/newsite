# Content Creation Skill

> Создание маркетингового и SEO-контента для сайта кейтеринговой компании в премиальном тоне бренда.

## Когда использовать

- При написании текстов для секций сайта
- При создании описаний услуг/меню
- При генерации meta descriptions, title tags
- При написании email-рассылок или сообщений
- При создании копирайта для рекламы

## Brand Voice & Tone

### Core Attributes

| Атрибут | Описание | Пример |
|---------|----------|--------|
| **Премиальность** | Без «дёшево», «выгодно», «скидки» | «Искусство застолья» |
| **Теплота** | Душевность, искренность, забота | «Создаём моменты» |
| **Чувственность** | Описания вкуса, атмосферы, эмоций | «Бархатный десерт», «хрустящая корочка» |
| **Точность** | Конкретика без воды | «16 лет», «2400+ мероприятий» |
| **Экспертность** | Знание дела, профессионализм | «Шеф-повар с опытом 20+ лет» |

### Tone Matrix

| Ситуация | Тон |
|----------|-----|
| Главная страница | Вдохновляющий, уверенный |
| О нас | Доверительный, гордый |
| Меню/Услуги | Аппетитный, детальный |
| Отзывы | Благодарный (от лица клиента) |
| Контакты | Приветливый, призыв к действию |
| FAQ | Информативный, успокаивающий |
| Ошибки формы | Вежливый, конструктивный |

### Запретные слова и фразы ❌

```
- «Вкусно и недорого»
- «Лучшие цены»
- «Гарантия качества» (без конкретики)
- «Качественный сервис»
- «Профессиональная команда» (без имён/опыт)
- «Низкие цены»
- «Выгодное предложение»
- «Скидки», «Акция», «Распродажа»
- «Отлично», «Хорошо», «Классно» (слишком общо)
- Emoji в заголовках (🎉 🥳 🔥)
```

## Section Templates

### Hero Section

```
Заголовок (H1): [Эмоциональный + ключевое слово]
- Макс. 8 слов
- Включает УТП или главное преимущество

Подзаголовок: [Раскрытие + социальное доказательство]
- 1-2 предложения
- Цифры, годы, количество

CTA: [Призыв к действию]
- Глагол + выгода
- «Рассчитать стоимость», «Обсудить меню», «Посмотреть портфолио»

Пример:
H1: Премиальный кейтеринг в Санкт-Петербурге
Sub: Создаём банкеты, которые запоминаются. 16 лет опыта, 2400+ мероприятий.
CTA: Рассчитать стоимость банка →
```

### About Section

```
Структура:
1. Манифест/миссия (2-3 предложения)
2. Цифры/факты (count-up анимация)
3. Ценности/подход (иконки + короткий текст)
4. Фото команды или процесса

Пример:
«Мы верим, что каждое мероприятие — это история, которую гости рассказывают годами.
Наше дело — сделать эту историю незабываемой.

16+ лет опыта
2400+ проведённых мероприятий
50 000+ довольных гостей
12 шеф-поваров в команде»

Ценности:
✦ Сезонность — работаем с тем, что даёт природа
✦ Ручная работа — никаких полуфабрикатов
✦ Индивидуальность — каждое меню уникально
```

### Menu Section

```
Структура типа меню:
1. Название типа (H3)
2. Короткое описание (1-2 предложения, аппетитное)
3. Цена «от X ₽/чел»
4. Что входит (буллиты)
5. Фото-пример блюда/сервировки
6. CTA → калькулятор

Пример для «Банкетное меню»:

Банкетное обслуживание

Классический банкет с полным циклом обслуживания — 
от разработки меню до уборки зала после мероприятия.

от 2 450 ₽ / человек

В стоимость входит:
• Разработка индивидуального меню (3 варианта на выбор)
• Полный сервис официантов (1 официант на 8-10 гостей)
• Посуда, столовое бельё, декор столов
• Шоу-кухня по запросу
• Координатор мероприятия

[Фото сервированного стола]

Рассчитать банкет →
```

### Services Section

```
Карточка услуги:
1. Иконка/иллюстрация
2. Название услуги (H4)
3. 1-2 предложения о сути
4. Ключевые особенности (3-5 буллитов)

Примеры названий:
- Банкетное обслуживание
- Фуршет на мероприятие
- Coffee-break для конференций
- Свадебный банкет под ключ
- Корпоративное событие
- Семейный праздник
- Выездной ресторан
- Кейтеринг на яхте/корабле
- Детский праздник
- Презентация / продукт-ланч
- Катеринг для съёмок
```

### Testimonials Section

```
Структура отзыва:
1. Фото-скриншот благодарственного письма (если есть)
2. Компания-клиент
3. Тип мероприятия + количество гостей
4. Дата проведения
5. Текст отзыва (от 1-го лица клиента)
6. Рейтинг ★★★★★

Пример:
«ООО "Спортинг"»

Корпоративный банкет · 150 гостей · 2014

«Коллегия выражает искреннюю благодарность за отличную организацию 
корпоративного банкета... Блюда были поданы своевременно, официанты 
внимательны и предупредительности. Все наши сотрудники остались очень 
довольны праздником.»

★ 5.0
```

### FAQ Section

```
Формат вопроса-ответа:
Q: [Вопрос от лица потенциального клиента]
A: [Ответ: конкретика + успокоение + CTA]

Примеры FAQ:

Q: Каково минимальное количество гостей для заказа?
A: Мы принимаем заказы от 10 персон для фуршетов и от 20 персон для 
банкетных программ. Для небольших семейных праздников предлагаем 
форматы «домашний банкет» или «премиум-фуршет». 

Q: Работаете ли вы за пределами Санкт-Петербурга?
A: Да, мы осуществляем выездное обслуживание по Ленинградской области 
и соседним регионам. Дополнительная логистика обсуждается индивидуально.

Q: Можно ли внести изменения в меню после утверждения?
A: Да, мы понимаем, что планы могут меняться. Изменения возможны за 
7 рабочих дней до мероприятия. При сокращении количества гостей более 
чем на 20% может применяться корректировка стоимости.

Q: Предусмотрена ли дегустация меню?
A: Конечно! Для банкетов от 50 персон мы предлагаем бесплатную 
дегустацию трёх блюд из утверждённого меню. Это помогает убедиться, 
что вкус полностью соответствует вашим ожиданиям.

Q: Как происходит оплата?
A: Стандартные условия: предоплата 50% при заключении договора, 
остаток — за 3 дня до мероприятия. Для корпоративных клиентов 
возможна постоплата по договору (при наличии договора на 
регулярное сотрудничество).
```

## SEO Copywriting Guidelines

### Keyword Integration

Естественное включение ключевых слов:
- Плотность: 1-2% (не keyword stuffing)
- В H1, первом абзаце, URL slug, alt-текстах
- LSI-слова (синонимы, связанные термины)

Пример:
```
Ключевое слово: «кейтеринг санкт-петербург»

✅ Хорошо:
«Премиальный кейтеринг в Санкт-Петербурге — создание banquet-меню, 
полный сервис обслуживания, индивидуальный подход к каждому 
мероприятию.»

❌ Плохо:
«Кейтеринг Санкт-Петербург. Наш кейтеринг в СПб — лучший кейтеринг. 
Закажите кейтеринг Санкт-Петербург недорого.»
```

### Meta Description Formula

```
[Главная польза] + [Уникальность] + [CTA] (до 160 символов)

Примеры:
«Премиальный кейтеринг в СПб: банкеты от 2450₽/чел. 16 лет опыта, 
2400+ событий. Индивидуальные меню, полный сервис. → Рассчитайте онлайн»

«Организация свадебного банкета в Санкт-Петербурге под ключ. 
Премиальное меню, шоу-кухня, декор. Бесплатная дегустация. → Узнать больше»
```

## Content Checklist

### Before Publishing
- [ ] Тон соответствует brand voice
- [ ] Нет запретных слов/фраз
- [ ] Цифры конкретны (не «много», а «16 лет»)
- [ ] CTA присутствует и понятен
- [ ] Текст сканируется (абзацы, буллиты, подзаголовки)
- [ ] SEO-ключwords включены естественно
- [ ] Грамматика и пунктуация проверены
- [ ] Alt-тексты для изображений написаны
- [ ] Длина соответствует секции (не «стена текста»)

### A/B Testing Ideas
- Длина описаний (короткое vs развёрнутое)
- CTA текст («Рассчитать» vs «Получить КП» vs «Обсудить»)
- Социальные доказательства (цифры vs цитаты vs фото)

## Tools for Content Creation

### LLM Prompts

```bash
# Генерация описания услуги
z-ai function -n llm -a '{
  "messages": [
    {"role": "system", "content": "Ты — copywriter премиального кейтеринга. Тон: тёплый, чувственный, точный. Без клише."},
    {"role": "user", "content": "Напиши описание услуги \"Банкетное обслуживание\" для сайта кейтеринга СПб. 3-4 предложения. Включи цену от 2450₽/чел. Добавь что входит."}
  ]
}'

# Генерация FAQ
z-ai function -n llm -a '{
  "messages": [
    {"role": "system", "content": "Генерируй FAQ для кейтеринг-сайта. Вопросы от лица клиента, ответы — конкретные + успокаивающие."},
    {"role": "user", "content": "Сгенерируй 8 FAQ вопросов про организацию банкета. Включи вопросы про цену, меню, изменение численности, оплату."}
  ]
}'
```
