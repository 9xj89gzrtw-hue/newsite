## 1. Десять заповедей (нарушал — платил циклами исправлений)

1. **Спрашивай о запрещённом, не только о желаемом.** Проверка «есть ли
   стейк?» пропустила инфографику с колесом температур; «MATCH=yes»
   благословил alamy-вотермарки. Любая проверка фото/кода обязана
   перечислять запреты явно: текст, вотермарки, логотипы, схемы, коллажи,
   наложения.
2. **Глазам VLM не верить — верить измерениям.** VLM «видел» обрезанные
   корешки (измерение: в пределах rack), «3 строки» заголовка (реально 1 —
   rotate раздувает bounding rect; строки считать через `clientHeight`),
   «сломанное меню» на рабочем. Скриншот — гипотеза, rect — факт.
3. **Пользователь — лучший критик.** Каждая его придирка циклов 51–54
   оказывалась реальным дефектом, который пропустили и VLM, и субагенты.
   Никогда не защищать свою работу перед юзером — чинить.
4. **Каждый элемент интерфейса отвечает на вопрос «что он делает для
   читателя СЕЙЧАС?»** Не отвечает — удалить. Так умерли: счётчик 01/12
   (тикал в 700px от взгляда), цифры на корешках (юзер дважды спросил
   «зачем они?»), ghost-цифры, hint-дубль.
5. **Заголовки никогда не рвутся посреди слова.** `overflow-wrap:anywhere`
   + процентный `max-width` в грид-колонке = «Вегетариан-ское». Только
   `normal`, перенос по пробелам, ширину ограничивает сетка.
6. **Декорация дешевле истины.** Пастельные тинты корешков юзеру
   понравились больше «кинематографичного» filmstrip-эксперимента.
   Вкусовые правки юзера отменяют любые «улучшения» агента.
7. **Копирайт — сенсорность + конкретика, ноль канцелярита.** Не
   «термоупаковка к 12:00», а «выпечка ещё тёплая, кофе пахнет на весь
   этаж». Запрещены: «техтайминг», «базовый» (само-дискредитация),
   «и настроение» (хвост-поздравление), списки существительных без глагола.
8. **Фото — главная валюта кейтеринга.** Замена фото = полный конвейер
   (см. §4). «Подходит по смыслу» ≠ «подходит по качеству»: все фото
   стойки обязаны быть одной кинематографической лиги (тёплый свет,
   глубина, премиум-фотобанки), иначе дешёвые тянут вниз дорогие.
9. **Верификация живого — только живым.** agent-browser эмулирует coarse
   pointer (hover/magnetic/parallax недоступны) и не применяет viewport
   после relaunch без проверки `window.innerWidth`. Fine-pointer фичи —
   Playwright-скрипт (шаблон `research/c50-verify.mjs`).
10. **Не «лучшее, на что способна» — а «лучшее, что проверяемо».
    Оценка VLM 7–9 одному кадру = шум. Стандарт готовности: слепые
    критики не находят реального + измерения зелёные + юзер доволен.

## 2. Технологические грабли (все — живые шрамы)

| Грабля | Симптом | Фикс |
|---|---|---|
| next/font vars на `<body>` | `:root`-токены (`--ea-font-*`) → invalid → весь сайт в ui-sans-serif | vars на `<html>` (layout.tsx) |
| sharp AVIF-энкодер висит | `/_next/image` с `Accept: image/avif` не отвечает вечно | `formats: ["image/webp", "image/avif"]` |
| Замена файла по тому же URL | Браузер отдаёт старую картину | новое имя файла (cache-bust) |
| `body { overflow-x: hidden }` | ломает `position: sticky` | `overflow-x: clip` |
| framer-motion `clipPath` string | рендерит `none` | SVG clipPath / императивный ref.style |
| `position: static` под absolute-слоем | контент тонет под z0-фото | `relative` + `z-index` |
| h3-обёртка c `min-width:auto` | ломает цепочку flex-ellipsis | `width:100%; min-width:0` |
| React Compiler deps | `preserve-manual-memoization` error | все читаемые значения в deps (даже `N`) |
| MultiEdit «атомарность» | часть edits применяется при ошибке | всегда rg-проверка фактического состояния |
| popLayout exiting-span | querySelector ловит СТАРУЮ цифру | проверка через ≥1.5с |
| scrollIntoView во время анимации | цель устаревает, перелёт | таймер после завершения (600ms) |
| image-search rate-limit | 429 при параллельных вызовах | последовательно, пауза 12–15с; VLM — пауза при 429 |
| Lenis + scrollIntoView | конфликт smooth-скролла | работает, но проверять позицию |

## §28 (Cycle 56): VLM-check process fix — defining object gate

**Грабля (доказательство C55→C56):** 4 фото в `/media/c55/` были
благословлены СТАРЫМ VLM-чеком, который спрашивал «на фото есть
бар/шеф/еда?» — тематический вопрос. Тема была, **определяющего
объекта не было** (бар-ресторан вместо портативного бара; фламбе
у стола вместо станции-оборудования; graze-доска без боксов;
готовый накрытый стол вместо логистики в процессе). 4/12 фото врут.

**Новый строгий чек (C56):** спрашивает ТОЛЬКО об определяющем
объекте услуги, называя обязательное и запрещённое явно. Формат:
`PASS: ДА/НЕТ` + `REASON` (2-3 предложения фактического описания).
См. `research/c56/check-current.mjs` и `verify-replacements.mjs`.

**Комбинированный гейт (object + watermark в одном VLM-вызове):**
`research/c56/gate-robust.mjs` — один prompt, две независимые
проверки: 1) определяющий объект visible? 2) есть ли
вотермарки/логотипы/бренды/инфографика/цифры/подписи? Выход строго:
`OBJ: ДА/НЕТ` + `OBJREASON` + `WM: НЕТ/ДА` + `WMNOTE`.
Survivor = objPass && wmClean. Это в 2 раза дешевле, чем два
отдельных VLM-вызова на каждое фото, и меньше 429-й.

**Backoff на 429 (VLM rate limit):** exponential, 8→16→32→64→128s
до 5 ретраев. Между вызовами ≥4s (увеличить до 10s если 429-е
сыпятся). Гейт также **resume-friendly**: пишет после каждого
изображения в `gate-results.json`, при перезапуске скипает ключи
из существующего файла — длинные гейты можно прерывать и
продолжать (важно при тул-лимите Bash в 10 мин).

**New-folder + new-filename cache-bust** (C53 открыта, C56 подтверждена):
файл-свап по тому же URL НЕ сбрасывает кэш Next/Image — юзер
видит старое фото. Решение: класть замену в `/media/c{N+1}/` с
новым именем (`c56-bar.webp` вместо `c55/bar.webp`), обновить путь
в `hacc-services.tsx`. Гарантированный буст кэша.

**Aesthetic re-check обязателен после gate-robust:** комбинированный
VLM иногда пропускает мелкие вотермарки (Coca-Cola на декоративной
тарелке, «KETTLE BRAND» внутри бокса). Финальный отбор survivors
прогонять через отдельный aesthetic-check (TONE/BLACKBG/CINEMA/
WMCHECK/SCORE), который переспрашивает про вотермарки в контексте
эстетики — иногда ловит то, что пропустил основной гейт.

**Honest alt-text** для каждого заменённого фото: описание того,
что буквально видно в НОВОМ фото, не копия аспирационного копи.
`alt` describes content, not the service promise.

## §31 (Cycle 59): слепой конфлав критиков + цены-в-один-экран

**Одно слово = одна цена на всём экране.** CFO-симуляции находят
orphan-цифры безошибочно (1600/2450, 450/900, 2000/2200, 1900/2450,
торт 4500 vs 8000). Любая промо-плитка/карточка обязана читать цену из
lib/pricing.ts; ручные строки «от N» — кандидаты на расползание. Если
продуктов два — разводить НАЗВАНИЯ («Свадебный торт» vs «Торты на
заказ»), не цифры.

**Fixed-офсет связан с высотой баннера.** FAB-lift −180px был подобран
под старый куки-баннер; после сжатия баннера до 77px тот же офсет сам
создавал дефект «кнопка лежит на строках». Меняешь один fixed-слой —
перемерь пересечения скриптом (fab-verify: прямоугольники текст-строк ×
FAB, допуск, hits==0).

**Headless-критикам — оговорка про coarse pointer.** agent-browser
эмулирует coarse → фичи за `(pointer:fine)` «мертвы» по определению;
без оговорки враг-критик пишет ложные MAJOR. Решение: нейтральный
Playwright-харнес (research/c59/fine-pointer-verify.mjs) с сырыми
числами + инструкция «помечай unverifiable, не «сломано»».

**Слепота повторных волн достижима:** новый субагент + запрет
worklog/AGENTS/research + нейтральные инструменты (без имён
«verify/fix») + новые персоны. 9 волн — ни одной утечки истории.

**«от X ₽» — только у минимума.** У выбранной не-минимальной ступени —
точная цифра; дефолт открытой панели = минимальный пакет (сходится с
калькулятором и лидом). Инверсия этого правила читается как обманка.

**Стоп-линия цикла критики:** требование критика, которое можно
выполнить только выдумав бизнес-факт (формула за кг, стек коэффициентов,
новый тип в калькуляторе), — не правка, а рекомендация владельцу.
Конституция запрещает изобретать данные (заповедь 1/7).

## §32 (Cycle 60): client-found defects — scroll cue + photo truth

**Fixed-step reveal врёт у дна (волна-2 блокер).** Шаг прокрутки (60–75%
высоты) не делится на произвольную высоту списка: счётчик «Ещё N» гас,
пока последняя строка срезана на 11–23px. Только scroll-to-bottom одним
кликом; подсчёт — bottom-rule (строка скрыта, пока её НИЗ ниже кромки) —
такой счётчик сходится в ноль ровно у дна, где паддинг показывает последнюю
строку целиком. Проверять батареей: count == числу срезанных строк во всех
стейтах, «клик → дно → кнопка исчезла → последняя строка читаема целиком».

**Переверстка аккордеона + неподвижный курсор = hover-hijack.** После
открытия панели корешки сдвигаются на ширину панели: под курсором,
«припаркованным» на только что кликнутом корешке, оказывается СОСЕДНИЙ —
и hover-intent через 380ms угоняет панель. Ловится живьём (5 кликов
подряд дёрнулись обратно). Фикс: suppress hover-intent ~700ms после
ЛЮБОГО open(). Слушатель скролла страницы обязателен рядом со слушателем
скролла списка, если логика зависит от позиции вьюпорта (баннер-лифт).

**IO с несколькими таргетами: entries пер-изменение.** `entries.some(e =>
isIntersecting)` в колбэке с 2+ таргетами врёт (уход одного таргета гасит
индикатор, пока второй в кадре). Держать `state[id] = isIntersecting` и
агрегировать по всем. Симптом: рельса-навигация не скрылась над рэком.

**Критикам — scoped-селекторы (волна-2 дала 3 ложных блокера).**
`querySelector('.hmenu__title')` в DOM с 7 панелями читает титул ПЕРВОЙ
категории всегда → «переключение не работает» на исправном коде. В промпт
критика включать правило: открытая панель читается только через
`.hmenu__item.is-open …`. Проверять их находки с правильными селекторами
до правок кода — но измеримые жалобы (счётчик/срезы) перепроверять СНАЧАЛА.

**Подпись-оверлей на узкой колонке = молчаливые потери.** line-clamp без
разборки контента режет хвост описания (−37px на 1024). Шаблон: имя и
описание — раздельные span'ы; на узких MQ описание скрывается целиком
(оно доступно в соседнем списке), а не зажимается.

**Фото-гейт отвергает всё подряд — не выдумывай.** 3 раунда поисков по

## §34 (Cycle 62): fixed-attachment параллакс — почему умер и как жить

**Любой предок с transform/will-change:transform/filter = смерть
`background-attachment: fixed`** (css-transforms-1 §3, css-will-change-1):
fixed молча деградирует до scroll. ClipPathReveal в c34 оборачивал фото
постоянным `willChange:"transform"` — эффект «картинка не двигается» был
мёртв 7 циклов, хотя комментарий в коде утверждал обратное. Комментарий —
гипотеза, измерение — факт: пиксельный диф 98.26% на 220px скролла до
фикса, корреляция строк best shift 0px (err 0.149 против 1.58 на ±2px)
после. Правило: fixed-слой живёт только в чистой цепочке предков до
`<html>`; reveal — SIBLING-панелью (clip-path на обложке, не предком).

**useReducedMotion() = hydration-мина при ветвлении дерева.** SSR: false;
клиент с reduce: true → «Hydration failed → tree regenerated» на всей
странице (жила с c34). Паттерн-фикс (единый для всех): mounted-гейт —
первый клиентский рендер обязан совпадать с SSR, ветка reduce свапается
после mount (`const [mounted,setMounted]=useState(false); useEffect(...);
const settled = mounted && reduce`). Сериализуемые пропсы (initial/
whileInView/variants/motionProps) — тоже ветвить только через settled.
Затронуто 13 файлов; fatal-случай закрыт; ОСТАЛИСЬ некритичные
attribute-warning'и под reduce: motion v12 сам снимает transform при
reduce (SSR не знает) — клиентское значение корректно, React оставляет
его. Глобальное лекарство — `MotionConfig reducedMotion="never"` + полный
аудит ручных гейтов (риск a11y-регрессии) — РЕШЕНИЕ ВЛАДЕЛЬЦА, не правка.

**animate prop ≠ whileInView для строковых значений не из variants:**
обложка-вайп сделана через `initial={{clipPath:"inset(0% 0% 0% 0%)"}}` +
`animate={inView ? {clipPath:"inset(100% 0% 0% 0%)"} : undefined}` —
строки с одинаковой токен-структурой интерполируются; onAnimationComplete
→ unmount (coverDone) — легальный пост-гидрационный апдейт.

**CSS-бг под тёмными градиентами:** q75 достаточно (512KB webp 1920w при
шумной листве; q82 давал лишь −3%). Двойная загрузка (CSS-фон + скрытый
next/image) — реальный проигрыш ~×1.8; один оптимизированный ассет +
новое имя = cache-bust (§28 третий укус предотвращён заранее).

**Харнес-гигиена:** пиксельный %-диф врёт на высокочастотных текстурах
(листва — 10-16% «дифа» при идеальном склей-эффекте из-за фазы растера);
корреляция профилей яркости строк отделяет сдвиг (0px err≪±1px err) от
растер-шума надёжно. `a ?? b` с void-функцией слева выполняет ОБА вызова
(lenis.scrollTo + window.scrollTo = двойной скролл) — на ?? с side-effect
функциями полагаться нельзя.

## §35 (Cycle 63): scroll-driven process strip — иерархия MotionValue, кириллица-фоллбек, reload-якорь

**Один MotionValue + per-step useTransform-слайсы = анимация без единого
setState.** `useScroll({target, offset:["start 0.85","start 0.35"]})` →
`useSpring` → рельс (`scaleX`/`scaleY`, оба в DOM aria-hidden, направление
выбирает CSS, не JS) + слайсы `[i/N·0.75, +0.25]` на opacity/scale шагов.
Скраб-путь чист: framer-подписки, ноль ререндеров, ноль long tasks.

**Вся декоративная геометрия — rem, не px.** Рельс `top-[62px]` отвалился
от точек на 30px при root 150% (соседи в rem). Формула: центр точки =
числовой бокс (rem) + полточки; `calc(0.25rem - 0.5px)` для центра 1px-линии.
Гейт: замер |dotCenter−railCenter| на 100% И 150% root — обязателен для
любых через-линий.

**ch-х нельзя смешивать между шрифтами.** `pl-[calc(2ch+0.75rem)]` резолвит
ch шрифтом САМОГО p (body ≠ numeral font) → 4px разъезда. Рабочий вариант:
фиксированный `w-[2ch]` на цифре (замерить фактическую ширину!) + pl в rem,
зависимость задокументировать в комментарии у элемента.

**Кириллический фоллбек шрифта не виден в computed font-family — только
CDP.** `.cep-text` (Neutra2, Latin-only) рендерил кириллицу Liberation Sans
через Karla-без-cyrillic-сабсета; computed style показывал «правильную»
стеку. Правда — `DOM.getPlatformFontsForNode`. Скоуп-фикс: inline
font-family на кириллический загруженный шрифт; ситевидное лечение сабсетом
— решение владельца (blast radius всего сайта).

**РReload-вспышка SSR-статики лечится связкой «layout-jump + passive
re-anchor».** SSR рисует полностью-активную статику (reduced-motion/no-JS
требуют); hydrate → `useLayoutEffect: line.jump(scrollYProgress.get())`;
дальше `scroll`-листер без interaction-маркера (pointerdown/wheel/touchstart/
keydown ставят флаг) пере-прыгивает на живое значение — реставрация скролла,
отстающая от гидрации на ~1с, больше не даёт коллапса. Проверка: rAF-сэмплы
fill после reload — минимум не ниже 0.4 от цели.

**`initial` framer-motion не перевооружается пост-монтом.** Если mounted-гейт
меняет `animate` после гидрации, `initial/whileInView` уже не армятся
(«мёртвый» вход). Фикс: `key={animate ? "a" : "s"}` — ремонт при флипе.

**Милые пол-пиксела WCAG тоже считает.** Промежуточный стейт анимации —
это тоже контраст: floor 0.45 на black/65 давал 2.02:1 (MAJOR слепого QA).
Гейт: opacity-фLOOR в замере при progress≈0.1 + арифметика α_eff в отчёте.

**Планшетная полоса 768–1279: 4 колонки голодают (186px).** 2×2 через
`md:grid-cols-2 xl:grid-cols-4`; через-рельс в бэнде не выживает (геометрия
второго ряда зависит от контента) → последовательная подсказка: красный
`scaleX`-андерлайн под глаголом (`md:max-xl:block xl:hidden`), тот же fill.

**Мой собственный верификатор врёт чаще продукта.** За цикл 3 бага харнеса:
rect.left элемента ≠ текст-край (padding!); fill-замер без скролла мерял
хвост; reload-проб на commit-фазе скроллил пустой документ. Факт до правки
(§33) — сначала чинить харнес, потом код. Измерения скриптом тоже
перепроверяются.

## §36 (Cycle 64): booking-сцена «Смета-чек» — слепые критики, WAAPI-замеры, live-тексты от часов

**Критик-блокер, опровергнутый 10-секундной пробой.** Волна-2 дала BLOCKER
«форма не принимает ввод» — fill() и keyboard.type на обоих вьюпортах
работали. Критик наполнил поля при закрытой форме/стейл-локаторе. Правило
§33 «факт до правки» расширить: ЛЮБОЙ «не работает ввод» сначала
воспроизвести двумя способами с явным кликом по полю; логику инпутов
не трогать, пока проба не воспроизвела дефект.

**framer-motion 12 анимирует clip-path через WAAPI: inline-стиль держит
ЦЕЛЕВОЕ значение, кадры видны только в getComputedStyle.** Замер «печати»
 PrintLine по el.style.clipPath всегда даёт end-state. Вторая ловушка:
querySelector один раз → remount по key → узел detached → computed «none».
Живой замер анимации: свежий querySelector каждый тик + computed-значения,
не равные end-state'ам.

**Бесконечных анимаций нет — но «живые» тексты от часов офиса дают
SSR↔клиент расхождение на границе минуты.** Динамическое обещание
перезвона (открыт/закрыт) ветвить только через mounted-гейт: SSR всегда
рендерит канон, свап после монта (§34). Unit-проверка обеих веток —
подменой часа в чистой функции, не моком Date на странице (мок Date
ломает todayIso/min-date и убивает submit).

**IntersectionObserver-логика «показать-скрыть» обязана иметь гистерезис
и per-target state.** Sticky-бар над cookie-баннером: CSS-переменная
высоты баннера через MutationObserver (баннер unmount'ится — слушатель
снять), переход — transition bottom 0.3s. Скрытие бара в «зонах»
(типы/CTA/контакты в нижней полосе) — per-target state map (§32),
иначе один уходящий таргет гасит всех.

**Термопечать строк = remount по сигнатуре значения.** `key={sig}` на
строке + initial clipPath inset(0% 100% 0% 0%) → animate 0%, стаггер 55мс;
reduced-motion/no-JS/SSR — статика (mounted-гейт). Анимировать только
transform/opacity/clip-path; ИТОГО не печатать (у него spring).

**Хит-арея без полноразмерной кнопки:** тики на рейке слайдера —
26px визуально + ::after inset(-4px -10px -16px) вниз в пустую зону;
полноразмерная кнопка перехватила бы драг. Проверка — elementFromPoint
на 14px ниже кнопки, не boundingBox (псевдоэлемент не растит rect).

**Мобильный пол кегля — переменной, не точечными правками.** Капс-шкала
2 уровня (eyebrow 12.5/0.18em, label 11.5/0.14em); на <768px
`--hb-caps-label-fs: 0.75rem` на корне блока — одинMEDIA-блок поднимает
все label-узлы (10.9–11.5px → 12px), desktop не тронут.

**Формат отображения ≠ формат данных.** Телефон: маска при blur
(formatPhoneDisplay, display-only, 10-значный ввод тоже), на сабмите —
normalizePhone (принимает любой из форматов). Черновик хранит сырой
ввод. Никогда не форматировать value в onChange — ломает caret.

## §37 (Cycle 65): слайдер-перф, char-ring, IO-полоса, React Compiler — 15 правок владельца

**Тач-драг умирает там, где над инпутом лежит кликабельная кнопка.**
Тики-пресеты сидели НАД range-инпутом: pointerdown в дефолтном положении
(30 = минимум = тик) перехватывался кнопкой — палец двигал «кнопку», слайдер
«тормозил». Зонирование: кнопке pointer-events:none, кликабельность —
полосой ::below (::after pointer-events:auto; у псевдоэлемента pointer-events
переопределяется КОНКРЕТНО, наследование none не мешает). Проверка удара —
elementFromPoint в координате полосы.

**Программный драг обязан быть кадровым.** Три слоя: rAF-коалесинг setstate
(пачка pointermove = 1 рендер), дебаунс URL-коммита (nuqs на кадр = history-
спам), дебаунс печатных строк чека (PrintLine remount по сигнатуре). Заливка
рейки — только scaleX (width = layout на кадр). Дебаунс-значение отдаётся и
memo-форме — иначе пропс guests перерисовывает её на каждый кадр.

**Стабильный onSuccess при memo-форме: ref-паттерн больше не проходит.**
React Compiler (eslint react-hooks) запрещает писать ref.current в рендере
и «Could not preserve existing memoization» на useCallback([])+ref-read.
Рабочая схема: колбек без замыканий на волатильные данные, снимок строит
ВЫЗЫВАЮЩИЙ (форма) из своих пропсов и передаёт аргументом.

**1ch обрезает цифры Prata.** В display-шрифтах без tnum ширины глифов
разные: 1ch = ширина «0» (≈0.53em), самый широкий глиф Prata 0.696em →
колонки одометра с overflow:hidden резали цифры («слипаются»). Фикс:
em-ширина по ЗАМЕРУ глифов (canvas/probe), не на глаз.

**Круговой текст: SVG textPath+textLength ненадёжен (Chrome плывёт).**
Рабочая техника — char-ring: N абсолютных <i>, инлайн
`translate(-50%,-50%) rotate(i·step) translateY(calc(-1*var(--r)))`,
вращается контейнер. Вторая ловушка: transform-формула «rotate вокруг
top-center + height=R» ставит глиф у ЦЕНТРА, не на окружности.

**IO-«нижняя полоса» режется верхним маржином, а не нижним.**
rootMargin "0px 0px -140px 0px" даёт зону наблюдения [0..vh-140]: «зона где
угодно выше полосы» (бар прятался почти всегда). Полоса снизу = УБРАТЬ
сверху: rootMargin "-83% 0px 0px 0px" (проценты — resize-безопасно);
isIntersecting ⇔ «элемент реально в нижней полосе».

**Адрес сайта: витринный ≠ юридический.** Публичные контакты (блок, футер,
JSON-LD) — CONTACTS.address (единый источник; YANDEX_MAPS теперь ссылается
на него); юридический адрес — только в /privacy,/terms,/offer
(LEGAL_INFO.legalAddress). Индекс в JSON-LD не выдумывать при смене адреса —
лучше отсутствие, чем чужой.

**FAB над мобильным sticky-баром.** Все fixed-кнопки внизу (BackToTop,
phone-FAB шапки) лифтятся ОДНИМ правилом
`body:has(.hb-bar[data-visible="true"]) :is(.fixed.bottom-6.left-6, .fixed.bottom-6.right-6)`
— замер пересечений при visible=true обязателен (переходы 0.3s ловятся
только устоявшимися rect).

ссылке даёт click, скролл работает (замер |Δ|=83).

для лёгких клипов с IO-гейтом. Пилюля-«Play» обязана честно отражать

## §43 (Cycle 72-2): перф-гейты ссылаются на числа, числа меняются — гейты пересматриваются

## §44 (Cycle 73): позиция курсора никогда не анимируется + Turbopack-CSS-грабли

**Лаг кастомного курсора не лечится тюнингом пружины.** Жалоба владельца
«курсор опережает кружок» = ring на spring 250/25 отставал ~200мс.
Архитектурный закон редизайна: ПОЗИЦИЯ пишется прямой записью
translate3d В ОБРАБОТЧИКЕ pointermove (transform = композитор, безопасно;
rAF-батчинг позиции добавляет кадр лага — для позиции его нет), спринги
живут ТОЛЬКО на масштабе (отдельный слой, иначе конфликт ручных и
framer-transform-записей). Движение-«характер» дают: деформация по
скорости («капля», rotate+scale по вектору, самозавершающийся rAF) и
магнит (весь курсор тянется к CTA). Юзабилити-минимум 2026: над
текстовыми полями системный I-beam (линза растворяется), у края окна
линза растворяется. Проверка регресса: `getComputedStyle(wrapper).transform`
строго равен координатам последнего события СИНХРОННО после mouse.move.

**Turbopack не всегда перебирает CSS-кэш.** Правка globals.css (новое
правило cursor:auto) отсутствовала в отданном браузеру CSS после touch+reload
— stylesheet-скан (document.styleSheets) показал старые правила; лечится
только рестартом pm2. Вывод: изменение globals.css в этой конфигурации
верифицировать по document.styleSheets, при расхождении — рестарт.
Догма «HMR подхватит» для tsx верна, для css — нет.

**Playwright-поиск «видимой интерактив-цели» на scroll=0 находит ничего**
(hero-табу §42: первый экран без ссылок) — верификация ховера обязана
сначала проскроллить к контенту. И `#calculator input` — это range
(гости), не text: тесты I-BEAM ищут input[type=text|tel|email] явно.

## §45. Cycle 74 — нативные scroll-driven эффекты: тонкости верификации

**VLM слеп к тонким элементам (<4px).** 2px полоса прогресса дважды
получала «не видна» от VLM при безупречных computed-стилях (rect
643×2, scaleX 0.4467, градиент рассчитан). Волосные линии/бордеры
проверяются ТОЛЬКО пиксельно: screenshot clip → drawImage →
getImageData по контрольным x. VLM — для сцен ≥100px.

**next/font: диапазон веса переменного шрифта — литерал "variable"**, не
строка "400..700" (TS-union в index.d.ts её отвергает). `weight:
"variable"` даёт VF со всей объявленной осью (Playfair 400 900).
Замер C74: Google и для статик-запросов отдавал VF-файлы — сеть до/после
идентична (331 856 Б), переключение схлопывает 33 @font-face в 9.
Прежде чем «оптимизировать» загрузку шрифтов — замерь, кого Google
реально отдёт: число деклараций ≠ числу файлов.

**Прелоадер запирает скролл.** Программный scrollTo во время intro
молча не действует; тесты скролла ждут завершения прелоадера (или
поллят scrollY). Иначе — ложные FAILы «эффект не работает».

**Позицию для клика/ховера считать от фактического
getBoundingClientRect** после скролла, никогда — от запрошенного
window.scrollTo значения (осадка Lenis/hydration смещает слой).
Проверено C74: Lenis программный скролл не перетаскивает (scrollY
стабилен), но привычка rect-функции цели исключает флейк.

**Прогресс-таймлайны (animation-timeline) проверяются в двух
позициях**: entry-промежуток (значение СТРОГО между крайами — ловит
реальную интерполяцию) и cover-финиш (значение = конечному). Одна
позиция доказывает только статику. `animation-duration: auto` —
обязательно явно (в shorthand по умолчанию 0s).

## §46. Cycle 75 — фиксы по итогам регрессии: три новых грабли

**Turbopack-CSS: рестарт pm2 НЕ гарантирует свежий CSS.** После правки
globals.css рестарт отдал СМЕСЬ: новое правило FAB + старые правила
паддингов из ОДНОГО исходного файла. Диагноз — выгрузкой живого
document.styleSheets (cssText) и сверкой с исходником; computed-стиль
= 108px при `var()`-правиле в файле = кэш, а не каскад. Лечение:
`pm2 stop` → `rm -rf .next` → `pm2 restart` → прогрев кёрлом
(первый запрос после вайпа = 35–40s компиляции; тест сразу после
рестарта ловит «баннер не найден» — грейть страницу ДО харнесса).

**VLM-критика полноэкранных скриншотов = 4/4 ложных срабатываний.**
Поляроид «накрывает текст» (столбцы x120–600 vs x748+), кнопка меню
«перекрывает блюдо» (зум-кроп: буквы читаемы, кнопка в fade-зоне),
«ПАР… обрезан» (артефакт скролл-анимации при снятии кадра). Полный
экран годится для ПОИСКА гипотез; решение принимает только rect-замер
или зум-кроп ре-ревью VLM. Иначе — фиксы несуществующих багов.

**AnimatePresence-exit против effect-cleanup.** Эффект с dep=[visible]
после setVisible(false) ПЕРЕ-выполняется, пока выходная анимация ещё
держит элемент в DOM: ref не пуст → эффект пере-ставит то, что cleanup
только что снял (C75: --cookie-banner-h оставался навсегда). Гвард
`if (!visible) return` в теле эффекта — обязателен, cleanup один
не спасает.

**Хардкод высоты fixed-панели = гарантированный §43-баг.** Число
«96px» в комментарии пережило два роста контента баннера (кнопки 44px,
метки «Необходимые»), реальная высота стала 150px. Живой замер
(ResizeObserver → CSS-переменная) дешевле одной регрессии: цифра в
коде переживает любые будущие правки контента. См. ea-cookie-banner.tsx
C75 и --cookie-banner-h в globals.css.

## §47. Cycle 76 — flex-shrink против «водяного знака» + ложные a11y-флаги inert-панелей

**Flex-item шире контейнера будет СЖАТ.** Гигантский водяной знак

**innerText-аудит доступности врёт на inert-поддеревьях.** Кнопки с
текстом внутри закрытых inert-панелей возвращают innerText='' —
наивный аудитор помечает их «безымянными», хотя inert исключает их из
a11y-дерева и фокуса ПО ОПРЕДЕЛЕНИЮ. Вердикт о доступности имени —
только по живому a11y-дереву (Playwright/snapshot accessibility tree),
не по innerText/computed-стилям. См. hacc-menu: 17 «дефектов» → 0
реальных (именованы все видимые табы, инертные скрыты целиком).

**Селектор с запятой теряет scope второго члена.** `'#hero a,button'`
= «все a внутри #hero И ВСЕ button вообще». Скопированный из секции
grep-паттерн `a,button` в querySelector даёт счёт ВСЕЙ страницы.
Писать полный префикс у каждого члена: `'#hero a, #hero button'`.

**Форма логотипа на странице — один источник.** Inline-SVG-компонент
(BrandBadge) с путями 1-в-1 из logo.svg и currentColor: вектор в любом
масштабе, цвет наследует раздел, ноль сетевых запросов. PNG-варианты
оставлять ТОЛЬКО там, где это preload-путь (прелоадер-бейдж, favicon,
og-image, JSON-LD logo) — иначе два источника правды разъедутся при
ребрендинге. Водяные знаки: tint через color-mix цвета (не opacity на
слое — маски/оверлеи слоя умножаются непредсказуемо), z:-1 внутри
isolate-контейнера, print-off, reduce-статика.
