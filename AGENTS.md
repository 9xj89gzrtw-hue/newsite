## 0. Кто я и что здесь строю

Сайт премиального кейтеринга «Interfood / nilov catering» (СПб, 16 лет, 2400+
событий). Репозиторий — рабочий цех: копируем лучшие решения с эталонных сайтов

## 1. Десять заповедей (нарушал — платил циклами исправлений)

1. **Спрашивай о запрещённом, не только о желаемом.** Проверка «есть ли
   стейк?» пропустила инфографику с колесом температур; «MATCH=yes»
   благословил alamy-вотермарки. Любая проверка фото/кода обязана явно
   перечислять запреты: текст, вотермарки, логотипы, схемы, коллажи.
2. **Глазам VLM не верить — верить измерениям.** VLM «видел» обрезанные
   корешки (замер: в пределах), «3 строки» заголовка (реально 1). Скриншот —
   гипотеза, rect — факт. В c81 VLM галлюцинировал ~60% CRITICAL-клеймов
   (критик E) — в таблицу дефектов только измеренное.
3. **Пользователь — лучший критик.** Каждая придирка циклов 51–54 — реальный
   дефект, который пропустили VLM и субагенты. Не защищать работу — чинить.
4. **Каждый элемент интерфейса отвечает «что он делает для читателя
   СЕЙЧАС?»** Не отвечает — удалить.
5. **Заголовки никогда не рвутся посреди слова.** `overflow-wrap: normal`,
   перенос по пробелам, ширину ограничивает сетка.
6. **Декорация дешевле истины.** Вкусовые правки юзера отменяют любые
   «улучшения» агента.
7. **Копирайт — сенсорность + конкретика, ноль канцелярита.** Запрещены:
   «техтайминг», «базовый», «и настроение», списки существительных.
8. **Фото — главная валюта кейтеринга.** Замена = полный конвейер §4.
   «Подходит по смыслу» ≠ «подходит по качеству»: одна лига кинематографичности.
9. **Верификация живого — только живым.** agent-browser не применяет viewport
   после relaunch без проверки `window.innerWidth`; fine-pointer — Playwright.
10. **Не «лучшее, на что способна» — а «лучшее, что проверяемо».** Оценка
    VLM 7–9 одному кадру = шум. Стандарт готовности: слепые критики не
    находят реального + измерения зелёные + юзер доволен.

## 3. Инфраструктура

```bash
bun install && prisma generate + db push   # DATABASE_URL=file:/home/z/my-project/newsite/db/custom.db (абсолютный!)
pm2 start ecosystem.config.js              # interfood-catering-dev, порт 3001
bun run lint && bun run typecheck          # оба зелёные перед коммитом — обязательно
# прод для Lighthouse: bun run build → cp -r .next/static .next/standalone/newsite/.next/
#   + cp -r public/. .next/standalone/newsite/public/ → pm2 start .next/standalone/newsite/server.js
#   --name interfood-prod-lh с env PORT=3002 HOSTNAME=127.0.0.1 (пример c81)
```

- **Порты:** 3000 — родительский sandbox (НЕ ТРОГАТЬ); 3001 — dev этот сайт;
  3002 — временный prod (для Lighthouse/e2e).
- **Lighthouse:** CHROME_PATH=/home/z/.cache/ms-playwright/chromium-1234/
  chrome-linux64/chrome + `--chrome-flags="--no-sandbox --headless=new
  --disable-gpu --disable-dev-shm-usage"`; вкладка крашится от OOM в конце —
  JSON всё равно полный.
- **Коммиты:** Conventional Commits; push БЕЗ force; перед push —
  `git diff --cached` глазами.
- **Субагенты:** каждый читает `/home/z/my-project/worklog.md` до работы и
  дописывает секцию после. Длинные задачи дробить (context-deadline!).
- **Скиллы:** web-search (версии/паттерны), image-search (фото), VLM
  (`z-ai vision`), agent-browser (e2e), Playwright (fine-pointer/точные
  замеры). Исследуй веб ПЕРЕД решением — «не изобретать колесо».

## 4. Конвейер замены фото (кровь циклов 51–55)

1. `z-ai image-search` — 8 кандидатов, последовательно с паузами.
2. Отсев: ≥1200px шириной, горизонтальные > портретных (панель ~2.1:1).
3. Строгий скан каждого: «есть ли текст/вотермарки/логотипы/инфографика?»
4. Гейт: «CINEMATIC=yes/no» против эталонного листа юзера.
5. Проверка кропа под аспект панели (sharp).
6. Конвертация: webp q82, width 1920; НОВОЕ имя файла.
7. Скриншот ПАНЕЛИ + VLM-чек в контексте.
8. **c81-дополнение:** rendered×2 ≤ natural запрошенного варианта — мерить
   через тело ответа (не naturalWidth, см. §2).

## 6. Тон бренда

Тёплый, чувственный, точный. «Еда как искусство»: сезонность, руки поваров,
ритуал застолья. Хук ≤ 90 знаков, глагол + сенсорная деталь. Запрещены клише
(«вкусно и недорого», «индивидуальный подход») и закупочный жаргон. Проверка
хука: «можно сказать шефу вслух за его столом?»
