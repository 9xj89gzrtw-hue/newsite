## 🔧 Как использовать этот каталог

### Для создания меню:
1. Открой `docs/menu-pdf-extraction/menu-items-complete.json` — 150+ готовых описаний блюд
2. Изучи `menu-design-analysis.md` — лучшие практики дизайна
3. Посмотри `wedding-menus.json` / `corporate-menus.json` — примеры пакетов

### For PDF Menu Creation:
1. Study `pdf-menu-links.json` — реальные PDF примеры
2. Use `dietary-menus.json` — система маркирования диет
3. Follow `menu-structures.json` — организация по категориям

### Для фотографий:
1. Read `photography-best-practices.md` — как снимать еду
2. Check `recommended-shots-list.md` — что именно снимать
3. Review `food-photo-analysis.md` — стили и композиция

### Для технической реализации:
1. Use `fonts-compilation.json` — какие шрифты использовать
2. Check `color-palettes.json` — цветовые схемы
3. Review `javascript-packages.json` — какие библиотеки нужны
4. See `analytics-setup.json` — как настроить аналитику

### Для пакетов услуг:
1. Study `wedding-packages-complete.json` — свадебные tier'ы
2. Review `corporate-packages-complete.json` — корпоративные форматы
3. Use `pricing-strategies.md` — стратегии ценообразования
