## 3. Претензии критика, отклонённые по факту

| Претензия | Фактический замер |
|-----------|-------------------|
| `/menu` и `/faq` → 404 = «критический баг» | Это **якоря** секций главной (`#menu` в `hacc-menu.tsx`, `#faq` в `ea-faq-accordion.tsx`). 404 на `/menu` корректен — маршрута не должно быть. |
| Телефон `+791****7205` «жив на проде» | Артефакт маскирования тул-вывода. Байтовая проверка: `asterisk=0`, `E164=True`, тот же SHA на диске и на проде. |
| На Vercel пустой `<h1>` | H1 содержит текст («Ресторанное качество…»); критик читал не тот селектор. |
| Vercel `robots.txt` «неполный» | Корректно отличается: `Sitemap` указывает на собственный домен зеркала. |

## 4. Осознанно НЕ делалось

- **CSP с `frame-src`** уже прописан, но интерактивная карта iframe удалена окончательно — оставлена
  статичная картинка как единственный вариант без чужой рекламы/POI без ключа API.

  а хардкод рейтинга грозит санкциями Google и претензиями по ФЗ «О рекламе».
- **`/certificates`, `/blog`** — нового контента нет, создать пустышки вредно для SEO.
