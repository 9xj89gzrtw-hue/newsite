### 4. IndexNow (единая отправка нескольким движкам)

  - **Bing** ✅

  - **Seznam.cz** ✅ (Чехия)
  - **Yep** ✅ (Россия/СССР)
- **Что делать (пошагово):**
  1. Убедиться, что файл `4455bbdfdb43656d43eeae6d6e0241c8.txt` доступен публично по адресу `https://nilovcatering.ru/4455bbdfdb43656d43eeae6d6e0241c8.txt`
  2. После каждого обновления/добавления страницы отправить POST-запрос:
     ```
     POST https://api.indexnow.org/indexnow
     Content-Type: application/json; charset=utf-8
     {"host":"nilovcatering.ru","key":"4455bbdfdb43656d43eeae6d6e0241c8.txt","urlList":["https://nilovcatering.ru/"]}
     ```
  3. Или отправить GET-запрос для одиночной URL:
     ```
     https://api.indexnow.org/indexnow?url=https://nilovcatering.ru/&key=4455bbdfdb43656d43eeae6d6e0241c8.txt
     ```
  4. При успешной отправке вернётся HTTP 200 (или 202 при первой отправке)
  5. В `robots.txt` должен быть указан `IndexNow: https://api.indexnow.org` и ключ
- **Статус для владельца:** ✅ Готово — ключ есть, нужно только добавить `IndexNow:` в `robots.txt` (проверьте!) и использовать для инкрементальной отправки URL

### Какие файлы загружать и куда
Все файлы верификации должны лежать в **корне сайта** `https://nilovcatering.ru/`:
```
https://nilovcatering.ru/google0b2a8b8f0c8a.html     ← Google
https://nilovcatering.ru/yandex_2dc6d5030c8a432b.html  ← Yandex
https://nilovcatering.ru/4455bbdfdb43656d43eeae6d6e0241c8.txt ← IndexNow key
```

### Meta-теги (альтернативный метод)
Если загрузка HTML-файлов невозможна, можно использовать meta-теги в `<head>`:
```html
<!-- Google -->
<meta name="google-site-verification" content="0b2a8b8f0c8a..." />
<!-- Yandex -->
<meta name="yandex-verification" content="2dc6d5030c8a432b..." />
<!-- Bing -->
<meta name="msvalidate.01" content="..." />  ← код генерируется при регистрации
```
