## CTA Placement in Journey Flow

### Optimal CTA Density by Scroll Position

```
SCROLL DEPTH    RECOMMENDED CTAs                    PURPOSE
═══════════════════════════════════════════════════════════════════

0% (Hero)      1 PRIMARY CTA                     Initial capture
                "Inquire About Your Event"
                
15% (Services)  1-2 SECONDARY CTAs               Interest building
                "Learn More" per service
                
35% (Social     1 SOFT CTA (optional)             Trust reinforcement  
 Proof)         "Read More Reviews" → external
                
50% (Gallery)   1 ENGAGEMENT CTA                  Visual engagement
                "View Full Gallery"
                
65% (Content)   1 CONTEXTUAL CTA                  Consideration push
                "See How This Works For You"
                
80% (Form)      1 PRIMARY CONVERSION CTA          Main conversion point
                "Check Availability" / "Submit"
                
95% (Footer)    1-2 SECONDARY CTAs               Exit capture
                "Subscribe" + "Contact Us"
                + Phone number always visible


CTA DENSITY RULE OF THUMB:
• Max 1 CTA per viewport (above fold)
• Max 2-3 CTAs visible at any time (below fold)
• Never have competing primary CTAs in same view
• Each scroll section should have ONE clear next action
```

## Friction Points & Drop-off Zones

### Common Friction Points Identified

```
FRICTION POINT HEATMAP:
═══════════════════════════════════════════════════════════════════

🔴 HIGH FRICTION (causes significant drop-off):

┌─────────────────────────────────────────────────────────────────┐
│  1. NO PRICING INDICATION WHATSOEVER                           │
│     User thinks: "Probably too expensive" or "Hidden costs"    │
│     Solution: Show starting prices or "Packages from $XX"      │
│                                                                 │
│  2. FORMS WITH 7+ REQUIRED FIELDS                             │
│     User thinks: "This will take forever"                      │
│     Solution: Progressive profiling, ask minimum first          │
│                                                                 │
│  3. NO PHONE NUMBER VISIBLE                                    │
│     User thinks: "They're hiding something" or "Hard to reach" │
│     Solution: Prominent click-to-call, especially mobile       │
│                                                                 │
│  4. SLOW MOBILE EXPERIENCE (>4s load)                         │
│     User thinks: "This site is broken, I'll try another"       │
│     Solution: Image optimization, lazy loading, minimal JS      │
│                                                                 │
│  5. GENERIC, STOCK PHOTOGRAPHY                                 │
│     User thinks: "This isn't a real business"                  │
│     Solution: Real event photos, team photos, behind-scenes     │
└─────────────────────────────────────────────────────────────────┘

🟡 MEDIUM FRICTION (causes some drop-off):

┌─────────────────────────────────────────────────────────────────┐
│  6. NO TESTIMONIALS OR REVIEWS VISIBLE                         │
│     Solution: Add testimonial slider or review badge            │
│                                                                 │
│  7. UNCLEAR SERVICE AREAS                                      │
│     User thinks: "Do they serve my area/type of event?"        │
│     Solution: Service area map, event type matrix               │
│                                                                 │
│  8. COMPLICATED NAVIGATION TO FIND INFO                        │
│     Solution: Clear information architecture, search function   │
│                                                                 │
│  9. NO DIETARY ACCOMMODATION INFO                              │
│     User thinks: "They can't handle my guests' needs"           │
│     Solution: Dietary icons, allergen statements                │
│                                                                 │
│  10. OUTDATED CONTENT (old dates, events)                      │
│      User thinks: "This business might not be active"           │
│      Solution: Current year references, recent blog posts       │
└─────────────────────────────────────────────────────────────────┘

🟢 LOW FRICTION (minor annoyances):
```

### Anti-Patterns to Absolutely Avoid

```yaml
anti_patterns_fatal:
  - name: "The Black Hole Form"
    description: "Long form with no indication of what happens after"
    impact: "70%+ abandonment at form stage"
    
  - name: "The Price Mystery"
    description: "Zero pricing information anywhere on site"
    impact: "Users assume unaffordable, never inquire"
    
  - name: "The Mobile Nightmare"
    description: "Site barely works on mobile devices"
    impact: "50%+ immediate bounce from mobile users"
    
  - name: "The Trust Void"
    description: "No testimonials, reviews, or social proof"
    impact: "Low credibility, users choose competitors"
    
  - name: "The Ghost Town"
    description: "No recent content, events from years ago"
    impact: "Users question if business still operates"

anti_patterns_significant:
  - name: "The Navigation Maze"
    description: "Complex menu structure, hard to find key info"
    
  - name: "The PDF Prison"
    description: "All menus locked in PDFs, not web-friendly"
    
  - name: "The Contact Obstacle Course"
    description: "Multiple steps required just to get a phone number"
    
  - name: "The Image Graveyard"
    description: "Slow-loading, unoptimized images everywhere"

anti_patterns_minor:
  - name: "The Carousel Confusion"
    description: "Auto-rotating hero that user can't control"
    
  - name: "The Pop-up Assault"
    description: "Immediate pop-up before user sees any value"
    
  - name: "The Font Fiasco"
    description: "Text too small or low contrast to read"
```
