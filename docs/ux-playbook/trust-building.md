## Review Aggregation Patterns

### Star Rating Display Variations

```html
<!-- Pattern 1: Aggregate Score Badge -->
<div class="rating-badge">
  <div class="score">4.9</div>
  <div class="stars">★★★★★</div>
  <div class="count">Based on 500+ reviews</div>
  <div class="source">Google · Yelp · WeddingWire</div>
</div>

<!-- Pattern 2: Platform-Specific Scores -->
<div class="platform-ratings">
  <div class="platform">
    <span class="icon">G</span> Google: ★★★★★ 4.8 (234 reviews)
  </div>
  <div class="platform">
    <span class="icon">Y</span> Yelp: ★★★★☆ 4.5 (189 reviews)
  </div>
  <div class="platform">
    <span class="icon">W</span> WeddingWire: ★★★★★ 5.0 (156 reviews)
  </div>
</div>

<!-- Pattern 3: Inline Review Snippet -->
<div class="review-snippet">
  <div class="header">
    <span class="stars">★★★★★</span>
    <span class="highlight">"Best caterer in DC!"</span>
  </div>
  <p class="excerpt">Ridgewells catered our company's annual gala and every guest...</p>
  <span class="attribution">— Sarah K., Google Review</span>
</div>
```

### Rating Integration Best Practices

| Practice | Description | Impact |
|----------|-------------|--------|
| **Show exact count** | "500+ reviews" not just stars | +18% credibility |
| **Multiple platforms** | Show Google, Yelp, WeddingWire together | +22% trust |
| **Link to source** | Clickable to actual review page | +15% verification |
| **Recent date** | "Updated last week" or similar | Prevents staleness concern |
| **Response shown** | Show owner reply to negative review | +30% confidence |

## Quick Implementation Checklist

### Minimum Viable Trust (Week 1)

- [ ] Add star rating aggregate near hero (even if modest score)
- [ ] Create "Trusted By" section with 6-10 recognizable logos
- [ ] Add "Serving [city] since [year]" to header or hero
- [ ] Include 2-3 photo testimonials with names/titles
- [ ] Add privacy/security note near contact forms

### Enhanced Trust (Month 1)

- [ ] Build full testimonial carousel/slider
- [ ] Create team section with headshots and credentials
- [ ] Add any relevant certifications as badge graphics
- [ ] Link to external review profiles (Google, Yelp, etc.)
- [ ] Include press/media section if applicable

### Maximum Trust (Quarter 1)

- [ ] Produce 2-3 video testimonials from happy clients
- [ ] Create before/after event gallery
- [ ] Develop case study pages for major event types
- [ ] Implement live social feed integration
- [ ] Earn or display industry awards/recognition
