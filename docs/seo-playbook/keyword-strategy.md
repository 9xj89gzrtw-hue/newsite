## Title Tag Formulas Discovered

### Formula 1: Brand + Tagline (Premium Brands)
```
[Brand Name] Catering | [Unique Value Proposition]
```
**Examples from analyzed sites:**
- `Wolfgang Puck Catering | The Standard for Culinary Excellence`
- `Global Gourmet Catering | Stellar Food. Seamless Service.`

### Formula 2: Service + Location (Local Focus)
```
[Quality Descriptor] [Service Type] [Location]
```
**Examples:**
- `Top Quality Full Service Off-Premise Catering With Elegant Affairs` (NYC, Hamptons)
- `Philadelphia's Premier Catering Company for Events & Weddings`

### Formula 3: Action-Oriented (Conversion Focus)
```
[Verb] Your [Event Type] with [Brand] | [Location] Catering
```
**Examples:**
- `Elevate your event with SaltBlock Hospitality's food and beverage experiences`

### Formula 4: Descriptive + Comprehensive
```
[Primary Service], [Secondary Service], and [Tertiary] | [Brand] | [Location]
```

## Meta Description Templates

### By Page Type:

#### Homepage (50-160 characters optimal)
```
Template A (Brand-focused):
[Brand] offers premium catering services for weddings, corporate events, and 
social gatherings in [Location]. [Unique selling point]. Contact us today!

Template B (Service-focused):
Looking for [quality] catering in [Location]? [Brand] provides 
[service types] with [differentiator]. Get your custom quote today!

Template C (Comprehensive):
[Brand] is [Location]'s choice for [event types]. From [menu highlight] to 
[service feature], we make every event memorable. Book now!
```

#### Service Page
```
Expert [service type] catering in [Location]. [Brand] delivers 
[key benefit] with [feature]. View our [CTA].
```

#### Gallery/Portfolio
```
Browse [brand]'s portfolio of [event type] catering. See our work at 
[venue types] throughout [region]. Inspiration for your next event.
```

#### About Us
```
Learn about [brand]'s story: [years] years of [specialty] in [Location]. 
Meet our [team description] and discover why clients choose us.
```

#### Contact Page
```
Contact [brand] for catering in [Location]. Call [phone] or request a 
quote online. We serve [areas served]. [Response time promise].
```

## Keyword Density Targets (Based on Industry Analysis)

| Element | Primary Keyword | Secondary Keywords | Location Term |
|---------|----------------|-------------------|---------------|

| Meta Description | 1-2x natural | 1-2x | 1x |
| H1 | 1x | Can include | Include if local |
| First 100 words | 1-2x | 2-3x | 1-2x |
| Body Content | 1-2% density | 0.5-1% each | 0.5-1% |
