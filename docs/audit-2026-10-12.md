# Аудит Nilov Catering

Проверка проекта `9xj89gzrtw-hue/newsite`, 12 октября 2026 года. Исправления проверены на изолированной копии: реальные заявки, письма, Telegram-сообщения и изменения рабочих данных не отправлялись.

## Исправления

- **Короткие адреса:** `/menu`, `/events`, `/contacts`, `/contact`, `/calculator` возвращали 404 до запуска клиентского перехода к разделу. Добавлены маршруты для Apache, Vercel и локального PHP-сервера.
- **Блокировка хранилища:** обращение к `window.localStorage` при загрузке модуля вызывало JavaScript-ошибку, если браузер запрещал хранение данных. Хранилище теперь необязательно для отправки формы.
- **Статусы заявок:** интерфейс мог сообщать «заявка сохранена» после отказа сервера либо неудачной записи в хранилище. Теперь отдельно обрабатываются подтверждение сервера, реально сохранённая очередь и ошибка без сохранения. Недоставленные заявки больше не считаются подтверждённой конверсией.
- **Повторная отправка:** повреждённые записи очереди с некорректным телефоном/полями отбрасываются, а не ломают цикл повторной отправки. Одновременно отправляемые формы отслеживаются отдельно для `sendBeacon`; завершение одной больше не отменяет страховку другой.
- **Совместимость и таймауты:** отправка использует `AbortController`, не требует `AbortSignal.timeout` и ограничивает ожидание ответа. Для запросов админки введён конечный таймаут с сохранением поддержки отмены запросов.
- **Калькулятор:** `NaN`/`Infinity` в числе гостей и индексе пакета больше не дают неопределённую стоимость.
- **Телефоны:** PHP и TypeScript одинаково нормализуют российские и международные номера, включая номера с точками в записи. Backend ограничивает количество цифр диапазоном 9–15.
- **Валидация меню:** синхронизированы обязательные поля, ограничения стоимости и длины строк, уникальность идентификаторов и минимальные заказы. PHP раньше мог принять данные, которые затем отвергала сборка.
- **Идентификаторы:** запрещены пути и недопустимые символы в идентификаторах форматов, допуслуг и плиток. Это исключает превращение идентификатора формата в путь при генерации PDF.
- **PDF на Vercel:** добавлена генерация PDF-меню, ранее отсутствовавшая в команде сборки зеркала. Проверка экспорта требует манифест и все 19 PDF.
- **Команды запуска:** `start` больше не ссылается на несуществующий `.next/standalone/server.js` при `output: "export"`. Для проверки статического экспорта и PHP API используется локальный PHP-сервер на порту 3001; `dev` тоже использует порт 3001 и сохраняет корректный код выхода.
- **Безопасность сборки:** сборка больше не применяет схему БД. Из явных команд работы с БД удалено автоматическое согласие на потерю данных.
- **CI и деплой:** добавлены тесты, проверка синтаксиса PHP и проверка статического экспорта. Публикация основного сайта предварительно требует успешных регрессионных проверок. Зафиксирована версия Bun, убран обход `--frozen-lockfile`.
- **Мобильное меню:** увеличена минимальная ширина вкладок, чтобы названия тарифов не переносились по одной букве.
- **Резервный компонент:** исправлена ссылка на отсутствующее изображение в CEP-видеокомпоненте.
- **Зависимости:** обновлены совместимые версии пакетов и адресно исправлены оставшиеся зависимости с доступными исправлениями. Обновлены GitHub Actions checkout/cache.

## Проверки

- **Автотесты:** 77 тестов, 0 ошибок; 253 проверки утверждений. Проверяются все 18 пакетов шести форматов, минимальные суммы, допуслуги, некорректные числа, форматы телефонов, схемы данных и защита `braces`.
- **PHP API:** локальный сервер с временным каталогом и фиктивным администратором. Проверены вход, cookie-флаги, выход с отзывом сессии, недоступность данных без авторизации, отклонение чужого Origin, согласие, валидация, запись заявки, нормализация и дедупликация.
- **Браузер:** основные страницы, админка и короткие адреса; размеры 1440 и 375 px. Ошибок JavaScript, повреждённых изображений и горизонтального переполнения в проверенных состояниях не обнаружено.
- **Форма заказа:** проверена отправка с подменённым локальным ответом API; четвёртый фуршетный пакет корректно передаётся как `pkgIdx: 3`, цена для 30 гостей — 160 500 ₽. Проверены ответы 400, 503 и отсутствие сети при запрещённом хранилище: отказ не создаёт ложную квитанцию, а сообщение о сохранении соответствует реально записанной очереди.
- **Админка:** локальный демо-режим; навигация по меню, допуслугам, минимальным заказам, плиткам, заявкам и настройкам. Рабочие данные не менялись.
- **Качество:** ESLint, TypeScript, синтаксис PHP и production static export проходят. Экспорт содержит страницы, endpoint-файлы и 19 корректных PDF; приватный `config/secrets.php` отсутствует.

## Остаточный риск и границы проверки

- **`braces`:** публичный advisory для версии 3.0.3 пока не содержит исправленной версии ([GitHub Advisory GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)). В репозитории сохранён Bun-патч с ограничением глубины разбора и рекурсивного обхода AST до 128 уровней; тесты проверяют обычные шаблоны и вход/AST глубиной 5000. `bun audit` продолжает показывать этот пакет по номеру версии: локальный патч является смягчением конкретной уязвимости, а не официальным upstream-релизом.
- **Реальные уведомления:** SMTP, Telegram, автоответ клиенту и последующие уведомления на рабочем хостинге не проверялись отправкой реальных сообщений. Для их end-to-end проверки нужна отдельно согласованная контрольная заявка.
- **Админ-публикация:** редактирование проверялось в демо-режиме, а авторизация — на локальном PHP API. Сохранение меню через рабочую админку в GitHub не выполнялось.
- **Область аудита:** это функциональная и техническая проверка доступного кода, а не гарантия отсутствия всех возможных ошибок или полноценный внешний пентест. Юридические тексты и коммерческий состав меню не пересогласовывались.

## Повторная проверка

```sh
bun install --frozen-lockfile
bun run lint
bun run typecheck
bun run test
bun run build
bun start
```

Для API-тестов и `bun start` необходим PHP CLI с `curl` и `mbstring`. Уведомления в автотестах отключены, настройки и заявки записываются только во временный каталог.
