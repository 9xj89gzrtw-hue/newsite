## 1. Package Structure Framework

### The Universal Catering Package Architecture

Every effective catering package follows this proven structure:

```
┌─────────────────────────────────────────────────────────────┐
│                    PACKAGE ANATOMY                          │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  ┌─────────────────────────────────────────────────────┐    │
│  │  1. PACKAGE NAME (Emotional + Descriptive)           │    │
│  │     Example: "Elegant Celebration Collection"        │    │
│  ├─────────────────────────────────────────────────────┤    │
│  │  2. PRICE ANCHOR (Range or Starting At)              │    │
│  │     Example: "From 8,000 ₽ per guest"                │    │
│  ├─────────────────────────────────────────────────────┤    │
│  │  3. TARGET AUDIENCE (Who is this for?)               │    │
│  │     Example: "Perfect for weddings 50-150 guests"   │    │
│  ├─────────────────────────────────────────────────────┤    │
│  │  4. CORE INCLUSIONS (What they GET)                  │    │
│  │     • Menu items                                     │    │
│  │     • Service level                                  │    │
│  │     • Equipment included                             │    │
│  │     • Coordination provided                          │    │
│  ├─────────────────────────────────────────────────────┤    │
│  │  5. VALUE DIFFERENTIATORS (Why THIS package)         │    │
│  │     • Exclusive features                             │    │
│  │     • Quality signals                                │    │
│  │     • Experience elements                            │    │
│  ├─────────────────────────────────────────────────────┤    │
│  │  6. CALL TO ACTION (Next step)                       │    │
│  │     Example: "Request Custom Proposal"              │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### Three-Tier System (Most Effective)

Research shows **3 tiers** outperform 2 or 4 options:

| Tier | Positioning | Price Point | Target |
|------|-------------|-------------|--------|
| **TIER 1: ENTRY** | "Classic" / "Essential" | Accessible | Budget-conscious, corporate lunches, casual events |
| **TIER 2: MID** | "Premium" / "Elevated" ⭐ | Sweet Spot | **MOST POPULAR** - Weddings, milestone events |
| **TIER 3: LUXURY** | "Bespoke" / "Elite" | Premium | Luxury weddings, VIP corporate, galas |

### Why 3 Tiers Work:

1. **Anchoring Effect**: Tier 1 makes Tier 2 look reasonable; Tier 3 makes Tier 2 look smart
2. **Choice Paralysis Avoided**: 3 options = manageable decisions
3. **Profit Optimization**: Most clients choose middle tier (designed for best margins)
4. **Upsell Path**: Easy to add "just a bit more" to reach next tier

## 2. Pricing Psychology for Premium Positioning

### Language That Commands Higher Prices

| AVOID (Commodity) | USE (Premium) | Psychological Impact |
|-------------------|---------------|---------------------|
| Cost / Price | Investment | Elevates perceived value |
| Cheap / Affordable | Accessible / Smart choice | Removes cheap perception |
| Package | Collection / Experience | Sounds bespoke |
| Included | Curated / Crafted | Implies intentionality |
| Basic / Standard | Classic / Essential | Neutral-positive framing |
| Expensive | Premium / Exclusive | Justifies higher price |
| Per person | Per guest | More respectful terminology |
| Additional cost | Enhancement option | Positive spin on upsells |

### The "Investment" Reframing Technique

**Before (Weak):**
> "Our wedding catering costs 12,000₽ per person."

**After (Strong):**
> "Your celebration deserves an investment in exceptional cuisine. Our Elegant Wedding Collection begins at 12,000₽ per guest—an investment your guests will remember long after the last bite."

### Price Display Strategies (Choose Your Approach)

#### Strategy A: Transparent (For Volume/Lower-Mid Market)
```
✓ Shows specific prices or ranges
✓ Reduces inquiry friction
✓ Attracts price-shopping clients
✗ May limit premium positioning
✗ Competitors can easily compare
```

**Best For:** High-volume caterers, standardized offerings, competitive markets

#### Strategy B: Semi-Transparent (Recommended Balance)
```
✓ Shows "starting at" or ranges
✓ Sets expectations without commitment
✓ Qualifies while attracting
✓ Maintains some premium mystique
```

**Best For:** Mid-to-high end caterers, most wedding specialists

#### Strategy C: Inquiry-Based (Ultra-Premium)
```
✓ Maximum perceived exclusivity
✓ Enables consultative selling
✓ Full price customization possible
✓ Qualifies leads effectively
✗ Higher barrier to inquiry
✗ May lose price-sensitive leads
```

**Best For:** Luxury/bespoke caterers, celebrity chefs, exclusive venues

### Psychological Pricing Tactics

#### 1. The Power of "Starting At"
> "Packages **starting at** 8,500₽ per guest"

- Sets a floor (not a ceiling)
- Feels accessible while allowing upselling
- Creates curiosity about higher tiers
- **Usage**: 78% of successful caterers use this

#### 2. Range Pricing
> "Investment range: **8,500 - 15,000₽ per guest** depending on customization"

- Manages expectations
- Accounts for menu variations
- Reduces sticker shock
- **Usage**: Common in semi-transparent approach

#### 3. Value-First, Price-Later Structure
Always communicate VALUE before revealing price:

```
CORRECT ORDER:
1. What's included (extensive list)
2. Experience description (emotional)
3. Social proof (others loved it)
4. THEN: Investment information
```

#### 4. Bundle Perception
Frame individual items as cohesive experience:

**Don't say:**
> "Food: 6,000₽ + Staff: 2,000₽ + Equipment: 1,000₽"

**Say:**
> "Complete Celebration Experience: From 9,000₽ per guest (includes menu, service staff, equipment, coordination)"

## 3. Package Naming Conventions That Sell

### Naming Formulas That Convert

#### Formula A: Aspiration + Event Type
- **Elegant Weddings Collection**
- **Celebration Essentials**
- **Corporate Excellence Package**

#### Formula B: Precious Metal Tiers (Universally Understood)
- **Silver / Gold / Platinum**
- **Bronze / Silver / Gold / Diamond**

*Pros: Instantly understood hierarchy*
*Cons: Can feel generic/corporate*

#### Formula C: Experience-Based Names (More Premium)
- **Classic / Elevated / Bespoke**
- **Essential / Enhanced / Extraordinary**
- **Curated / Artisan / Prestige**

*Pros: Sounds more bespoke, less commodity*
*Cons: Requires explanation*

#### Formula D: Emotional/Evocative Names (Luxury Positioning)
- **Timeless Moments Collection**
- **Grand Celebration Experience**
- **The Legacy Package**

*Pros: Highest emotional connection*
*Cons: Must deliver on promise*

## 4. Inclusions Checklist by Tier

### TIER 1: CLASSIC/ENTRY LEVEL
**Target Price Point:** 5,000 - 8,500₽ per person

| Category | Standard Inclusions | Notes |
|----------|---------------------|-------|
| **Menu** | 3-course meal (2 entrée choices), buffet OR plated | Simpler execution |
| **Service Style** | Buffet preferred, or basic plated | Lower labor cost |
| **Staff Ratio** | 1:15-20 guests | Efficient staffing |
| **Equipment** | Basic linens (white/ivory), standard glassware, chafing dishes | Functional, not fancy |
| **Bar** | Available as add-on only | Not included base |
| **Coordination** | Basic timeline, day contact | Limited involvement |
| **Setup/Cleanup** | Included within 8-hour window | Standard coverage |
| **Tasting** | Not included | Add-on available |
| **Menu Customization** | Choose from set options | No full customization |

**Best For:** Corporate lunches, casual dinners, bridal showers, birthday parties, budget weddings

---

### TIER 2: PREMIUM/ELEVATED ⭐ MOST POPULAR
**Target Price Point:** 8,500 - 15,000₽ per person

| Category | Standard Inclusions | Notes |
|----------|---------------------|-------|
| **Menu** | 4-course meal (4-5 entrée choices), any service style | More variety |
| **Service Style** | Plated, buffet, or family-style (client choice) | Flexible |
| **Staff Ratio** | 1:10-12 guests | Attentive service |
| **Equipment** | Upgraded linens (color options), premium glassware, specialty displays | Better presentation |
| **Bar** | Beer & wine OR signature cocktail package included | Value-add |
| **Appetizers** | 1 round passed hors d'oeuvres OR 1 action station | Elevated cocktail hour |
| **Coordination** | Full timeline creation, vendor liaison, rehearsal attendance | Involved support |
| **Setup/Cleanup** | Included within 10-hour window | Extended coverage |
| **Tasting** | Included for up to 4 people | Builds confidence |
| **Menu Customization** | Semi-custom - chef adapts from templates | Personalized feel |
| **Special Touches** | Welcome table, place cards, menu cards | Details matter |

**Best For:** Weddings (most common choice), anniversaries, corporate galas, milestone birthdays, holiday parties

---

### TIER 3: BESPOKE/LUXURY
**Target Price Point:** 15,000+₽ per person (often 25,000-50,000+₽)

| Category | Standard Inclusions | Notes |
|----------|---------------------|-------|
| **Menu** | Unlimited customization, chef's tasting menu format, rare/premium ingredients | No limits |
| **Service Style** | Multi-style (cocktail reception + plated + dessert stations) | Full experience |
| **Staff Ratio** | 1:8-10 guests + dedicated captain + maître d' | White-glove service |
| **Equipment** | Designer linens, crystal/museum-quality rentals, custom furniture/floral | No compromise |
| **Bar** | Premium open bar (top-shelf), custom cocktails developed for event | Full luxury |
| **Appetizers** | Multiple passed rounds + multiple action stations + grazing tables | Abundance mindset |
| **Coordination** | Dedicated event producer, multiple planning meetings, full vendor management | Concierge-level |
| **Setup/Cleanup** | Unlimited hours, overnight prep if needed, full teardown | Whatever it takes |
| **Tasting** | Private chef tasting for up to 6, multiple rounds if needed | Complete confidence |
| **Menu Customization** | 100% bespoke - client vision realized | True collaboration |
| **Special Touches** | Custom signage, floral integration, entertainment coordination, luxury amenities | Unforgettable details |
| **Exclusives** | First access to new menu items, priority booking dates, relationship perks | VIP treatment |

**Best For:** Luxury weddings, celebrity events, VIP corporate, charity galas, society debuts, destination events

| **Social/Private Party** | 5,000 - 15,000 ₽ | 3,000 - 10,000 ₽ |

*Note: Luxury/celebrity events can exceed 50,000₽/person in major cities*

### Cultural Pricing Expectations

#### Differences from Western Markets

| Aspect | Western Practice | Russian Market Adaptation |
|--------|------------------|---------------------------|
| **Price Transparency** | Often hidden ("contact us") | **More expected** - show ranges |
| **Negotiation** | Rare in premium segment | **Common** - build in room |
| **Inclusions** | Many add-ons common | **Expect more inclusive** packages |
| **Service Charge** | Explicitly stated (18-22%) | **Often bundled** into total |
| **Gratuity** | Separate suggestion | **May be included** or not expected |
| **Payment Terms** | Deposit + final payment | **Similar**, but may negotiate installments |
| **Contract Formality** | Detailed contracts | **Important** - Russians respect formality |

### Recommended Pricing Communication for Russian Market

#### DO:
- ✅ Show price ranges (not just "contact us")
- ✅ Use ₽ (rubles) as primary currency
- ✅ Include EUR/USD reference for international clients
- ✅ Be clear about what's included vs. extra
- ✅ Offer 3 clear package tiers
- ✅ Build in negotiation room (10-15%)
- ✅ Emphasize quality and exclusivity
- ✅ Use formal but warm language tone

#### DON'T:
- ❌ Hide all pricing (seems suspicious in RU market)
- ❌ Use overly casual language
- ❌ Surprise clients with hidden fees
- ❌ Be inflexible on negotiation
- ❌ Ignore the importance of face-to-face meetings
- ❌ Underprice (signals low quality in premium segment)

### Seasonal Patterns in Russia

| Period | Pattern | Pricing Implication |
|--------|---------|---------------------|
| **Декабрь - Январь** (New Year) | HIGHEST DEMAND | Premium pricing, book 6+ months ahead |
| **Июнь - Август** (Wedding Season) | HIGH DEMAND | Peak rates, limited availability |
| **Май, Сентябрь** | MODERATE-HIGH | Shoulder season, good availability |
| **Ноябрь, Февраль-Март** | LOWER DEMAND | Potential discounts, better availability |
| **Будние дни** (Weekdays) | ALWAYS LOWER | 15-25% discount opportunity |

## 9. FAQ & Objection Handling Copy

### Frequently Asked Questions (Price-Related)

#### Q: Сколько стоит свадебный банкет?
**A:** Наши свадебные коллекции начинаются от 8 500 ₽ на persona. Финальная стоимость зависит от выбранного меню, формата обслуживания, количества гостей и дополнительных услуг. Большинство наших пар выбирают коллекцию «Премиум» на уровне 14 000-18 000 ₽/чел.

---

#### Q: Что входит в цену? Есть ли скрытые платежи?
**A:** Мы придерживаемся принципа полной прозрачности. В указанную стоимость всегда входят: выбранное меню, работа сервисной команды, базовый реквизит (скатерти, посуда, приборы), организация и уборка в оговорённое время. 

Дополнительно могут оплачиваться: барное сопровождение (по желанию), специальные станции, аренда уникального реквизита сверх стандартного комплекта. Все дополнительные позиции согласовываются заранее и фиксируем в договоре.

**Скрытых платежей нет.**

---

#### Q: Можно ли договориться о скидке?
**A:** Для событий в будние дни (понедельник-четверг) и в низкий сезон (ноябрь-март) мы предлагаем скидки до 20%. Также действуют специальные условия для постоянных клиентов и при бронировании нескольких событий в год.

Мы стараемся предложить максимально выгодные условия, поэтому рекомендуем обсудить бюджет на консультации — часто мы можем предложить альтернативы, которые помогут оптимизировать стоимость без потери качества.

---

#### Q: Как происходит оплата?
**A:** Стандартные условия:
- **Предоплата:** 30% при подписании договора (фиксирует дату)
- **Остаток:** за 10 дней до мероприятия
- **Финальное количество гостей:** подтверждается за 7 дней

Принимаем наличные, банковские карты и безналичный расчёт. Для крупных событий возможна оплата в рассрочку — обсудите индивидуально с менеджером.

---

#### Q: Выезжаете ли за город / в другие регионы?
**A:** Да, мы организуем мероприятия любой локации. Для событий за пределами [город/регион] добавляется транспортная надбавка (расчитывается индивидуально в зависимости от дистанции) и, при необходимости, проживание команды.

Многие наши лучшие события прошли на уникальных локациях за городом — нам нравится новые вызовы!

---

#### Q: Минимальное количество гостей?
**A:** Для формата полного сервиса минимальное количество — 30 персон. Для меньших компаний мы можем предложить:
- Формат «выездного ресторана» (меню сервируется, но меньше персонала)
- Коктейльный формат (фуршет, меньше复杂性)
- Доставку готовых наборов (для совсем камерных встреч)

Свяжитесь с нами — мы подберём оптимальный формат!
