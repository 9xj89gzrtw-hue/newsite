# Process & Workflow Descriptions Analysis

**Generated:** 2026-01-20  
**Sources Analyzed:** 15 catering websites

---

## Executive Summary

### How Catering Sites Describe Their Process:

1. **Step-Based Workflows**: Most common format - clear numbered steps
2. **Consultation-First**: Emphasis on initial consultation/meeting
3. **Timeline Guidance**: Information about when decisions need to be made
4. **Day-of Reassurance**: Staff presence and coordination promises
5. **Post-Event**: Less commonly mentioned but valued when present

## Template 2: Timeline-Based Process

```
YOUR EVENT TIMELINE

INITIAL INQUIRY (Anytime before event)
→ Submit inquiry form or call
→ Receive response within 24 hours
→ Schedule consultation

CONSULTATION (6+ months before ideal)
→ In-person or video meeting
→ Menu vision discussion
→ Preliminary pricing overview
→ No obligation, no pressure

PROPOSAL (Within 48 hours of consultation)
→ Detailed custom proposal
→ Menu recommendations
→ Itemized investment breakdown
→ Terms and availability confirmation

BOOKING (When ready)
→ Signed agreement
→ Deposit secures date (typically 25-50%)
→ Assigned event coordinator

MENU FINALIZATION (30 days before)
→ Tasting appointment (if desired)
→ Final menu selections
→ Dietary requirements confirmed
→ Beverage selections locked

FINAL COUNT (7-14 days before)
→ Guaranteed guest count due
→ Final timeline distributed
→ Vendor coordination confirmed

EVENT DAY
→ Team arrives early for setup
→ Professional service throughout
→ Seamless breakdown and cleanup

POST-EVENT (Within 1 week)
→ Thank you communication
→ Feedback request
→ Photo gallery (if applicable)
```
