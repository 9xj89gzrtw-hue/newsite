## 2. Юнит-экономика NILOV CATERING

Считаем на примере мероприятия на 50 гостей. Маржа кейтеринга — 30–35% (еда, логистика, персонал — примерно 65–70% чека).

| Формат | Цена/чел | Чек (50 чел) | Маржа ~30% | Макс. цена сделки | Макс. цена лида* |
|---|---|---|---|---|---|
| Фуршет | от 2 450 ₽ | 122 500 ₽ | ~36 700 ₽ | 36 700 ₽ | ~12 800 ₽ |
| Банкет | от 4 470 ₽ | 223 500 ₽ | ~67 000 ₽ | 67 000 ₽ | ~23 500 ₽ |
| BBQ | от 2 900 ₽ | 145 000 ₽ | ~43 500 ₽ | 43 500 ₽ | ~15 200 ₽ |
| Доставка закусок | от 1 200 ₽ | 60 000 ₽ | ~18 000 ₽ | 18 000 ₽ | ~6 300 ₽ |
| Кофе-брейк | от 900 ₽ | 45 000 ₽ | ~13 500 ₽ | 13 500 ₽ | ~4 700 ₽ |

\* при конверсии лида в сделку 35%. При конверсии 30% — на 15% ниже, при 50% — выше.

**Максимальная цена сделки** = вся маржа, то есть ноль в ноль по первому заказу. Реально мы хотим зарабатывать, поэтому рабочая цель — тратить на привлечение не больше 10–12% выручки (у премиального кейтеринга норма ДРР 8–12%).

**Формула окупаемости — просто:**

> Реклама окупается, если: **цена лида < маржа одного заказа × конверсия лида в сделку.**
>
> Пример, фуршет: 36 700 ₽ × 0,35 = **12 845 ₽**. Всё, что дешевле 12 800 ₽ за лида по фуршетным запросам, — прибыльно даже с одного заказа.
>
> А с запасом (ДРР ≤ 10%): цена лида ≤ 4 300 ₽ по фуршету и до ~7 800 ₽ по банкету.

**Проверка на реальных каналах:** реальные лиды из Директа стоят 1 000–3 000 ₽, с Авито — 87–400 ₽. Это в 4–10 раз ниже порога окупаемости. Узкое место не «дорого», а «мало заявок» — поэтому и нужен этот план.

**Бонус, который меняет всё — повторные клиенты.** Корпоративный клиент за 2–3 года делает 3–6 заказов (новый год, 8 марта, летний BBQ, юбилеи). Значит, реальная ценность корпоративного лида ×3–6 к марже первого заказа: лид за 2 000 ₽ может принести 100 000+ ₽ маржи.

## 3. Бесплатные каналы — сделать ПЕРВЫМИ (эта неделя, 0 ₽)

Зачем первыми: 40% пользователей выбирают услугу по карточке и отзывам, ещё до захода на сайт (revvy.ai, 2025). Карточки работают 24/7 без бюджета и повышают конверсию платной рекламы — человек проверяет вас перед звононом.

### 3.1. Яндекс Бизнес (главная бесплатная карточка)

**Шаги (2–3 часа):**

1. Зайти на `https://business.yandex.ru` → «Добавить организацию» (вход по Яндекс-ID).
2. Категория: **«Кейтеринг»** (+ «Доставка обедов», «Организация мероприятий» как дополнительные).
3. В поле **«Сайт»** указать nilovcatering.ru — это привязка карточки к домену.
4. Загрузить **логотип крупнее 200×200 px** и 10–15 лучших фото с мероприятий.
5. В названиях/описании добавить варианты написания: «NILOV CATERING», «Нилов Кейтеринг», «nilov catering», «ИП Нилова А.Д.» — так карточка находится и по кириллическому запросу «нилов кейтеринг».
6. Указать телефон +7 (911) 941-72-05, часы работы, зону выезда (СПб + Ленобласть).

**Эффекты:**

- Показы в Поиске Яндекса, Картах, Навигаторе и ответах Алисы — бесплатно.
- **SEO-бонус (наш R1-анализ): большой логотип в выдаче Яндекса показывается ТОЛЬКО из карточки Яндекс Бизнеса** — разметкой на сайте его получить нельзя. Это делает сниппет в поиске заметнее конкурентов.
- Отзывы в карточке видны прямо в выдаче.

### 3.2. Отзывы — самый дешёвый «канал» вообще

1. Составить список 30–40 недавних мероприятий (у вас 2400+ событий — есть из чего выбрать).
2. Позвонить/написать 10–15 контактным лицам: «Будем благодарны за пару строк о нашей работе — ссылка: [ссылка на отзыв в Бизнесе]».
3. Цель: **15–20 отзывов за 1–2 месяца** — это порог, после которого имеет смысл думать о платных каталогах.
4. На каждый отзыв отвечать 1–2 строками — это тоже видно клиентам.

Важно: не просить «оставить 5 звёзд», просить честный отзыв — выживают только настоящие.

**Ожидаемый эффект блока 3:** первые 3–10 заявок в месяц без бюджета + рост конверсии платных каналов. Срок появления карточек в выдаче — от пары дней до 2–3 недель.

## 4. Яндекс Директ — главный платный канал

### 4.1. Почему стратегия «Оплата за конверсию»

Обычный Директ = платите за клики: кликнул человек — минус деньги, заявка или нет — не важно. В 2026 году клики дорожают на 20–90% в зависимости от ниши (vc.ru, июнь 2026).

Режим **«Оплата за конверсию»** = платите только когда человек **отправил заявку** на сайте. Риск «показал рекламу, денег нет, заявок нет» переноcится на Яндекс. Именно этот режим делает Директ безопасным для вашего требования «точно окупилось».

**Параметры режима:**

- Максимальная цена конверсии в Директе поднята до **50 000 ₽** (блог Click.ru, сентябрь 2025; раньше было 5 000 ₽).
- Мы ставим не максимум, а **1 500–3 000 ₽ за заявку** — с запасом под окупаемость (порог для фуршета ~12 800 ₽).
- Конверсия = цель **lead_submit** в Метрике (она уже настроена на сайте — см. раздел 12).

### 4.3. Бюджет и настройки

- **Поисковые кампании: 40–60 тыс. ₽/мес** (порог входа формально от 300 ₽ пополнения, недельный автобюджет от 300 ₽ — direct.yandex.ru, март 2026; рабочий тест — ~5 000 ₽/нед на кампанию).
- Гео: **Санкт-Петербург + Ленинградская область** (не вся Россия — доставка еды дальше 50 км не делаем).
- Стратегия: «Максимум конверсий» с оплатой за конверсии, цена конверсии 1 500–3 000 ₽.
- Цель: **lead_submit** (заявка с сайта). Вторично можно добавить tel_click, когда появится статистика.
- Объявления: в заголовок — формат и город («Фуршет под ключ в СПб»), в текст — «от 2 450 ₽/чел, 16 лет, 2400+ мероприятий» + телефон.
- Быстрые ссылки: Фуршет / Банкет / Кофе-брейк / Калькулятор.
- На каждую группу запросов — своя посадочная страница (страница формата, не главная).

**Ожидаемый результат:** цена заявки 1 500–3 000 ₽, 15–30 заявок/мес с 40–60 тыс. ₽ бюджета. ДРР при средней сделке 120–170 тыс. ₽ — 10–15%, при банкетах — заметно ниже.

### 4.4. Ретаргетинг в РСЯ — догнать тех, кто не оставил заявку

Человек посмотрел меню, покрутил калькулятор, ушёл подумать. Это самый тёплый трафик.

- **Бюджет: 10–15 тыс. ₽/мес.**
- Аудитория 1: были на сайте за последние 30 дней, НЕ отправили заявку.
- Аудитория 2 (стоп): те, кто отправил заявку или звонил — исключить, деньги на них не тратить (калькулятор-стоп).
- Креативы: лучшие фуд-фото + короткий текст «Фуршет от 2 450 ₽/чел · расчёт сметы за 5 минут · +7 (911) 941-72-05».
- Важно: только ретаргетинг. Широкая «холодная» РСЯ без аудиторий — слив бюджета (см. раздел 11).

**Пример из ниши:** реальный кейтеринг в Директе держал ДРР 16,45% даже при масштабировании бюджета на +30% (vc.ru, сентябрь 2026). Наша цель жёстче — 10–12%, и она достижима на «оплате за конверсию».

## 6. Telegram — каналы СПб (события, ивенты, офисы)

**Цифры рынка:** тема «Еда и кулинария» — CPM 3,7 €, один из самых низких CPC — 0,4 € (elama.ru, февраль 2026). С августа 2026 минимальный CPM в российских кабинетах на таргетинг по каналам снижен с 1 € до **0,15 €** (sostav.ru) — точечный закуп стал доступен малым бюджетам. Но CPM за 2 года вырос на 60–80% (vc.ru, декабрь 2025) — значит, покупаем **узко**, а не «всех подряд».

**Бюджет: 15–25 тыс. ₽/мес.**

**Два способа:**

1. **Прямые посты в СПб-каналах (проще и дешевле начать).** Прямой пост в городском канале — 400–900 ₽ за 1000 просмотров (sky.pro). Целимся в:
   - городские ивент/афиша-каналы СПб (подписчики — организаторы и гости событий);
   - бизнес-сообщества и чаты офис-менеджеров/HR СПб (корпоративы, кофе-брейки);
   - каналы «переезд/офис/свадьбы СПб».
   - 3–4 поста/мес × 3–7 тыс. ₽ = 10–25 тыс. ₽. Каждый пост с UTM-ссылкой (раздел 12).
2. **Telegram Ads через кабинет (позже, месяц 2–3).** Таргетинг на «мини-каналы» — узкие тематические каналы про еду и события. Вход после того, как бесплатные карточки и Директ уже дают поток.

**Креатив:** 1 сильное фото стола + 3 строки: «Фуршет для команды от 2 450 ₽/чел. Готовим на вашей площадке, привозим всё до вилки. 16 лет, 2400+ событий. Смета за 5 минут: +7 (911) 941-72-05».

**Ожидание:** 5–15 переходов на пост в среднем канале; цена перехода 15–40 ₽; при конверсии сайта 3–8% — лид за 500–1 500 ₽.

## 7. VK — сообщество + lookalike + ретаргетинг

**Почему не в топ-3:** холодный таргет VK в премиум-нише работает хуже Директа (человек не ищет кейтеринг, пока ему не нужно). Зато VK силён в двух вещах: **lookalike** (похожие на ваших посетителей) и **ретаргетинг**. Официальный кейс VK по кейтерингу — рост через ведение сообщества и контент, не через холодный CPM (vk.ru, февраль 2025). Кейс в event-индустрии: 2,4 млн ₽ выручки за 6 месяцев, окупаемость ×10 (агентство Церебро, сентябрь 2025).

**Бюджет: 10–15 тыс. ₽/мес** — только после того, как на сайте накопилось 500+ посетителей (обычно 3–4 неделя Директа) — есть из чего строить lookalike.

**Платная часть:**

- Lookalike по посетителям сайта (сегмент из Метрики/VK Ads — аудитория ретаргетинга сайта).
- Гео СПб + ЛО, возраст 25–55, интересы «мероприятия/рестораны/бизнес».
- Формат: универсальная запись с фото стола + кнопка «Получить смету».
- Ретаргетинг по тем, кто interacted с сообществом.

**Бесплатная часть (сейчас):**

- Вести сообщество VK: 2–3 поста в неделю — фото с мероприятий (у вас архив на 2400+ событий), сезонные меню, «как проходит фуршет на 200 человек».
- Закрепить пост с калькулятором и телефоном.
- Сообщество = вторая витрина + база для ретаргетинга.

**Ожидание:** лид 300–1 000 ₽ на lookalike/ретаргетинге; главный вклад — прогрев и узнаваемость в СПб.

## 8. Свадебное направление — самый выгодный сегмент

**Числа, которые меняют приоритеты:** свадебный кейтеринг считается **от 12 000 ₽ на гостя (база) до ~30 000 ₽ (комфорт)** (alveowed.com, сентябрь 2026). Это в 3–7 раз выше корпоративных 2 450–4 470 ₽. Одна свадьба на 50 гостей при 15 000 ₽/гость = **750 000 ₽ выручки**, ~225 000 ₽ маржи — как **5–10 корпоративных фуршетов**.

Свадьбы бронируют за 3–9 месяцев: реклама свадебного направления в сентябре–феврале продаёт сезон май–сентябрь.

**Каналы (бюджет: 10–20 тыс. ₽/мес с сентября по февраль):**

| Канал | Что делать | Ставка |
|---|---|---|
| Горько.ру | Портфолио (платное размещение) — портал жив, правила размещений обновлялись в июне 2026. Загрузить 10–15 лучших свадебных фото + цены «от». | разово/мес |
| Свадебные организаторы СПб | Письмо/звонок 15–20 организаторам: агентское вознаграждение **5–10%** от чека за приведённую свадьбу. Организаторы постоянно ищут надёжный кейтеринг. | % с заказа |
| Площадки «чистая локация» | Лофты, усадьбы, шатры без своего питания — оставить меню и визитки консьержу/менеджеру, предложить 5–10% или взаимные рекомендации. | %/бартер |
| Отели | Консьерж-службы отелей — та же схема партнёрского вознаграждения. | % |
| Директ | Кампания «кейтеринг на свадьбу спб» уже в списке (раздел 4) — отдельная посадочная с свадебными фото. | клики |

**Что выставить напоказ:** не «вкусно», а стабильность — 16 лет, 2400+ событий, выезд на любую площадку, свои повара и официанты, полный цикл (мебель-посуда-сервис). Свадебный клиент платит за отсутствие рисков.

## 9. Корпоративный B2B — где живут повторные заказы

Корпоративный клиент — это LTV ×3–6: декабрьский корпоратив → кофе-брейки на конференции → 8 марта → летний BBQ. Заказы December — **~30% годового кейтеринга** (catering-muscat.ru, 2023), бронируются в сентябре–ноябре.

**Три действия:**

1. **База прошлых клиентов — рассылка (0 ₽, самая высокая отдача).** У вас 2400+ мероприятий — многие компании живы и меняют ответственных. Сентябрь–октябрь: письмо/WhatsApp «Мы готовили у вас фуршет в [год]. Бронируем декабрь — в прошлом году лучшие даты разобрали к концу ноября. Посчитаем смету на ваш бюджет?». Персонализировать по компании — конверсия 5–15% (у холодных подписчиков — доли процента).
2. **Ивент-агентства — агенты, а не конкуренты.** 10–15 агентств СПб, которые организуют конференции и форумы без своего производства. Агентское вознаграждение 10–15% (для агентств) — они приносят заказы с чеком 100–500 тыс. ₽ и не тратят ваш рекламный бюджет. Письмо + одно знакомство вживую на профильной встрече.
3. **HR и офис-менеджеры.** Их ищут там же: Директ по запросам «кофе-брейк для конференции», «кейтеринг на корпоратив» (уже в разделе 4) + LinkedIn-аналоги и бизнес-чаты TG (раздел 6). Оффер: «Смета за 5 минут, без выездных встреч, договор и закрывающие документы для бухгалтерии» — для B2B это половина решения.

**Санити-чек по ценам:** в промышленном B2B квалифицированный лид в Директе стоил 22 500 ₽ при бюджете 45 000 ₽ (sostav.ru, март 2026). Ваша цель — в 5–10 раз ниже (1 500–3 000 ₽), потому что кейтеринг — массовый спрос с горячими запросами, а не длинные промышленные циклы. Если увидите SQL дороже 5 000 ₽ — что-то не так в настройках.

## 11. Что НЕ делать (сэкономленные деньги = заработанные)

1. **Meta (Instagram / Facebook) реклама — юридически недоступна.** Meta признана экстремистской организацией в РФ, таргетированная реклама там для российского бизнеса запрещена. Любой, кто предложит «настроить Инстаграм-рекламу» — предлагает либо серую схему через зарубежные кабинеты (риск блокировки и потери денег), либо нарушение закона. Инстаграм-архив можно вести как витрину, но рекламных денег туда нет.
2. **Широкая холодная РСЯ / медийные баннеры «на всех».** РСЯ без ретаргетинга и узких сегментов — классический слив: платите за показы людям, которым кейтеринг сейчас не нужен. РСЯ — только ретаргетинг (раздел 4.4).
3. **Платные каталоги до накопления отзывов.** Кейс (vc.ru, 2021): оплатили размещение в каталоге, «забыли» — деньги сожжены без отзывов и рейтинга. Правило: платный каталог — только после 15–20 живых отзывов на бесплатных карточках.
4. **CPA-сети и «гарантированные лиды» от подрядчиков.** Лиды приходят из нецелевых форм и накруток. Ваша «оплата за конверсию» в Директе — тот же CPA, только честный и с вашей ценой.
5. **Всё и сразу.** Каждый новый канал — только после того, как предыдущий измерен 2 недели по Метрике. Порядок из этого документа — не случайность.
6. **Оплата за показы/охваты где бы то ни было.** Охваты не пьют шампанское на ваших фуршетах. Платим за клики, заявки, конверсии.

## 12. Измерение окупаемости — цели Метрики уже стоят

На сайте уже настроены 5 целей Яндекс Метрики. Ничего нового внедрять не надо — только смотреть раз в неделю.

### 12.1. Что означает каждая цель

| Цель Метрики | Что значит | Как использовать |
|---|---|---|
| **lead_submit** | Отправлена заявка с сайта | **Главная.** По ней = цена лида (CPL) по каждому каналу |
| calc_start | Начали считать в калькуляторе | Самый тёплый интерес: человек прикидывает бюджет |
| form_open | Открыли форму заявки | Качество трафика: много form_open и мало lead_submit → форма пугает |
| tel_click | Нажали телефон на сайте | Офлайн-лид: человек позвонил — засчитывать вместе с заявками |
| messenger_click | Клик в Telegram/WhatsApp | Офлайн-лид: человек ушёл в мессенджер |

### 12.2. Формулы

> **CPL канала** = расходы канала за месяц ÷ (lead_submit + tel_click + messenger_click) этого канала.
>
> **ДРР канала** = расходы канала ÷ выручка закрытых заказов этого канала. Норма: ≤ 10–12%, тревога: > 15%.
>
> **Конверсия сайта** = lead_submit ÷ посетители. Норма 3–8%, лучшие — 15–20% (brutalmarketing.me). Если ниже 2% — сначала чинить сайт, не наращивать бюджет.

Закрытые заказы привязывайте к источнику вручную: при каждом звонке — «По какому запросу/где нас нашли?» — и записывать. Через месяц это таблица из 30 строк, дающая честный ДРР.

### 12.3. Еженедельный ритуал — 15 минут (например, пятница 10:00)

1. Метрика → Отчёты → «Конверсии» за 7 дней, сегмент/группировка по **utm_source** (или отчёт «UTM-метки»).
2. Заполнить 5 строк таблицы (завести в Excel/Google Sheets):

| Канал | Расход, ₽ | lead_submit | tel/mess. клики | CPL, ₽ | Действие |
|---|---|---|---|---|---|
| yandex | | | | | |
| avito | | | | | |
| telegram | | | | | |
| vk | | | | | |
| прямой/карточки | | | | | |

3. Правила решений:
   - CPL ≤ 2 500 ₽ → увеличить бюджет канала на 20–30% на след. неделю;
   - CPL 2 500–5 000 ₽ → оставить, копить статистику;
   - CPL > 5 000 ₽ при расходе > 3 000 ₽ → выключить кампанию/объявление, переписать текст или посадочную;
   - РСЯ-ретаргетинг не трогать по CPL — он работает на возврат «думающих», оценивать раз в месяц.

### 12.4. UTM-разметка — готовые ссылки

Без UTM Метрика не разделит каналы. Прописывать в конце URL каждого объявления/поста:

**Директ, поиск (в параметрах URL объявления):**
```
https://nilovcatering.ru/?utm_source=yandex&utm_medium=cpc&utm_campaign=poisk-furshet&utm_content={phrase_id}&utm_term={keyword}
```
(в каждой кампании своё `utm_campaign`: `poisk-banket`, `poisk-kofebrek`, `poisk-korporativ`, `poisk-bbq`, `poisk-svadba`, `poisk-brend`)

**РСЯ-ретаргетинг:**
```
https://nilovcatering.ru/?utm_source=yandex&utm_medium=cpc&utm_campaign=rsya-retargeting
```

**Авито (в ссылке «сайт» в профиле/объявлениях):**
```
https://nilovcatering.ru/?utm_source=avito&utm_medium=listing&utm_campaign=uslugi-furshet
```

**Пост в телеграм-канале:**
```
https://nilovcatering.ru/?utm_source=telegram&utm_medium=post&utm_campaign=spb-event-kanal-imya
```
(имя канала в campaign — увидите, какой канал привёл)

**VK Ads:**
```
https://nilovcatering.ru/?utm_source=vk&utm_medium=cpc&utm_campaign=lookalike
```

**Горько.ру (ссылка из портфолио):**
```
https://nilovcatering.ru/?utm_source=gorko&utm_medium=portfolio&utm_campaign=svadby
```

Правило одно: у каждого объявления — своя пара `utm_source` + `utm_campaign`. Тогда таблица из 12.3 заполняется из Метрики за минуты.
