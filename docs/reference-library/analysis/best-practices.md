# Best Practices for Catering Websites

> Recommended approaches based on competitive analysis

## 1. Hero Section Best Practices

### Do:
- ✅ Use high-quality, authentic food/event photography
- ✅ Keep headline under 10 words (ideally 5-7)
- ✅ Include clear value proposition in subheadline
- ✅ Place primary CTA above the fold
- ✅ Ensure text is readable over background (overlay if needed)
- ✅ Consider video background for premium feel (use sparingly)

### Don't:
- ❌ Use stock photos that look generic
- ❌ Write lengthy hero copy (save for below fold)
- ❌ Hide contact info behind clicks
- ❌ Use low-contrast text on busy backgrounds

## 2. Navigation Best Practices

### Structure Recommendations:
```
[Logo] [About] [Services] [Gallery] [Contact CTA]
```

- Keep main nav to 4-6 items maximum
- Always include visible contact/CTA in header
- Make phone number clickable on mobile
- Use dropdowns for sub-categories (not main level)

### Mobile Navigation:
- Hamburger menu is expected
- Include "Call Now" sticky button
- Consider bottom nav for key actions

## 3. Service Presentation

### Effective Patterns:
1. **Icon + Title + Description** cards
2. **Tabbed interface** for service categories
3. **Image-led** service showcases
4. **Pricing transparency** (or "Starting at" ranges)

### Service Categories to Include:
- Weddings
- Corporate Events
- Social Events/Private Parties
- Off-Premise/Catering Delivery
- Special Diets/Restrictions

## 4. Gallery/Portfolio

### Best Practices:
- Filter by event type (weddings, corporate, etc.)
- Lightbox/fullscreen view option
- Include event details (venue, guest count approx.)
- Mix of wide shots and detail shots
- Before/after or setup/execution pairs work well

## 5. Trust & Social Proof

### Essential Elements:
- Professional photography (shows capability)
- Client logo strip (name-drop without words)
- Testimonials with names/photos when possible
- Awards/certifications display
- Years in experience badge

### Optional but Effective:
- Instagram feed integration
- Video testimonials
- Case study deep-dives
- Press mentions/logo wall

## 6. Lead Capture

### Contact Form Fields (Priority Order):
1. Name (required)
2. Email (required)
3. Phone (required)
4. Event Type (dropdown)
5. Event Date (date picker)
6. Estimated Guest Count (number/range)
7. Message/Details (textarea)

### Form Placement:
- Header CTA → Landing page with form
- Dedicated Contact page (full form)
- Sidebar/sticky form on key pages
- "Quick Inquiry" simplified form variants

## 7. Performance & Technical

### Speed Optimization:
- Compress images (WebP with fallback)
- Lazy load below-fold images
- Minimize custom fonts (2-3 max)
- Use CDN for static assets
- Target < 3 second load time

### SEO Essentials:
- Unique title tags per page
- Meta descriptions with local keywords
- Schema markup (LocalBusiness, Event)
- Alt text on all images
- Mobile-first indexing ready

## 8. Accessibility (WCAG 2.1 AA)

### Minimum Requirements:
- Color contrast ratio 4.5:1 (text)
- Keyboard navigable
- Focus indicators visible
- Form labels associated properly
- Alt text on meaningful images
- Skip-to-content link

### Nice to Have:
- Accessibility statement page
- Font size adjuster
- Screen reader testing completed

## 9. Content Strategy

### Pages Every Catering Site Needs:
1. Home (hero + overview + CTAs)
2. About (story, team, values)
3. Services (detailed offerings)
4. Menus (sample or full)
5. Gallery (portfolio proof)
6. Weddings (dedicated if >20% of business)
7. Contact (form + info + map)
8. FAQ (common questions answered)

### Optional High-Value Pages:
- Blog (SEO + thought leadership)
- Careers (hiring pipeline)
- Venues (if multiple locations)
- Process/Timeline (what to expect)

## 10. Conversion Optimization

### Key Metrics to Track:
- Contact form submissions
- Phone calls (tracking number)
- Menu downloads (if applicable)
- Time on site per page
- Bounce rate by source

### Quick Wins:
- Add chat widget (Tawk.to, etc.)
- A/B test hero CTA copy
- Create landing pages for each service
- Implement exit-intent popup (carefully)
- Add urgency where appropriate ("Limited dates")

---
*Compiled from analysis of 22 competitor sites | 2025-01-15*
