## How to Use This Library

### For AI Agents

When starting any task related to the catering website:

1. **Read this file first** (`MASTER-INDEX.md`) to understand what's available
2. **Check `REFERENCE-SITES-ANALYSIS.md`** for overall patterns and recommendations
3. **Navigate to specific section** based on task type (see Quick Start above)
4. **Cross-reference multiple sources** - e.g., for a landing page, check both UX playbook AND content library

### For Human Developers

1. **Design Phase**: Start with `DESIGN-SYSTEM.md` + reference screenshots
2. **Copy Phase**: Use `content-library/` for all text content needs
3. **Development Phase**: Reference `technical-playbook/` + `reference-library/patterns/`
4. **Launch Phase**: Run through `seo-playbook/technical-checklist.md`
