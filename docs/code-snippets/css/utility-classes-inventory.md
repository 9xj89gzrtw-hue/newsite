## Recommended Utility Classes for New Project

Based on frequency analysis, these utility patterns should be included in your design system:

### Layout Utilities
```css
.container { /* Main container */ }
.content-wrapper { /* Content wrapper */ }
.row { display: flex; flex-wrap: wrap; }
.col { flex: 1; }
.w-full { width: 100%; }
.h-full { height: 100%; }
```

### Positioning Utilities
```css
.relative { position: relative; }
.absolute { position: absolute; }
.top-0 { top: 0; }
.left-0 { left: 0; }
```

### State Utilities

.is-active { /* Active state */ }

## Notes on Class Naming Conventions

1. **BEM-like patterns**: `block__element--modifier`
   - Example: `info-item__text`, `splide__slide--clone`

2. **State prefixes**: `is-`, `pre-`, `has-`
   - Example: `is-active`, `is-visible`, `preFade`, `preSlide`

3. **Framework-specific**: CMS/platform classes often have prefixes
   - Squarespace: `sqs-`
   - Wix: `wixui-`
   - Elementor: `elementor-`
   - Oxygen: `oxy-`

4. **Styled Components**: Hashed class names from CSS-in-JS
   - Pattern: `ComponentName__hash-sc-{hash}`
