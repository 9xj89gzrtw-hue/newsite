> **Purpose:** Comprehensive checklist of all trust-building elements for catering websites

## Overview

This checklist helps ensure your website includes all essential trust-building elements. Use it to audit existing sites or plan new ones.

**Scoring System:**
- ✅ = Implemented
- ⚠️ = Partially implemented
- ❌ = Not implemented
- 🚫 = Not applicable

## Category 1: Social Proof (Reviews & Testimonials)

### Written Testimonials
- [ ] Testimonials displayed on homepage
- [ ] Dedicated testimonials/reviews page
- [ ] Testimonials on relevant service pages (weddings, corporate, etc.)
- [ ] Customer names included (first + last, or first + initial)
- [ ] Customer titles/roles included where appropriate
- [ ] Event types mentioned in testimonial context
- [ ] Specific praise points visible (food quality, service, etc.)
- [ ] Photos of clients included (with permission)
- [ ] Star ratings displayed alongside text reviews
- [ ] Dates or timeframes shown (e.g., "Wedding, June 2024")
- [ ] Mix of event types represented (weddings, corporate, social)
- [ ] Video testimonials available
- [ ] Ability to filter testimonials by event type
- [ ] Links to external review platforms (Google, Yelp, The Knot, etc.)

### Review Platform Integration
- [ ] Google Reviews widget/embed
- [ ] The Knot / WeddingWire reviews linked (for wedding caterers)
- [ ] Yelp profile linked
- [ ] Facebook reviews accessible
- [ ] Overall aggregate rating displayed
- [ ] Review count shown (e.g., "Based on 127 reviews")
- [ ] Recent reviews featured with dates

## Priority Implementation Guide

### Phase 1: Essentials (Do First)
These have highest impact for effort required:

- [ ] Add testimonials to homepage (3-5 strong ones)
- [ ] Display years in business prominently
- [ ] Include "About Us" with founding story
- [ ] Show team member photos/bios
- [ ] Ensure contact info is easy to find
- [ ] Fix any visual/design issues
- [ ] Link to external review profiles

### Phase 2: High Impact (Do Next)
Builds significantly on essentials:

- [ ] Create dedicated testimonials page
- [ ] Add client logo display section
- [ ] Showcase awards and certifications
- [ ] Build portfolio/gallery with case studies
- [ ] Integrate Google Reviews widget
- [ ] Embed Instagram feed
- [ ] Add stats/numbers section

### Phase 3: Enhancement (Polish)
Differentiates from competitors:

- [ ] Video testimonials
- [ ] Detailed case studies
- [ ] "As Seen In" press section
- [ ] Blog with educational content
- [ ] Community/impact section
- [ ] Satisfaction guarantee statement
- [ ] Timeline/milestones visualization

### Phase 4: Advanced (Competitive Edge)
For maximum trust optimization:

- [ ] Interactive portfolio filters
- [ ] Staff credential detail pages
- [ ] Sustainability/impact report
- [ ] Client outcome metrics
- [ ] Industry speaking/expertise showcase
