## 0. Диагностика (что уже установлено инструментами)

| # | Факт | Как проверено |
|---|------|---------------|
| D1 | `http://nilovcatering.ru` отдаёт **200 OK**, а не 301 на https | `curl -sI http://…` → `HTTP/1.1 200 OK` |
| D2 | На живом сайте **нет ни одного security-заголовка** (HSTS, CSP, X-Content-Type-Options, Referrer-Policy, X-Frame-Options) | `curl -sI https://…` — только `server: nginx` |
| D3 | В репо `.htaccess` **сознательно** не делает редирект http→https (комментарий c92, строки 10–13: «SSL терминирует nginx-фронт, Apache видит http») | чтение `public/.htaccess` |
| D4 | Карта = `https://yandex.ru/map-widget/v1/…` в iframe. Виджет принимает **только** `ll`, `z`, `l` — параметра отключения рекламы нет; он грузит `yandex.ru/ads/system/context.js` и рекламные запросы (подтверждено GitHub-issue #762 silentroach/kpshelkovo) | `src/lib/media.ts:240` + веб-поиск |

## 1. Чеклист «задача решена» + измеримые критерии

Каждый пункт — с командой проверки. Ни один пункт не закрывается без её зелёного результата.

### Блок 1. Надёжность/безопасность (устраняет «небезопасную ссылку» ВК)
- [ ] **C1.1** `curl -sI http://nilovcatering.ru/` → **301** с `Location: https://nilovcatering.ru/`
- [ ] **C1.2** `curl -sI https://nilovcatering.ru/` содержит `Strict-Transport-Security`, `X-Content-Type-Options: nosniff`, `Referrer-Policy`, `X-Frame-Options`
- [ ] **C1.3** Редирект **не зацикливается**: `curl -sIL http://…` обрывается 200 за ≤5 прыжков
- [ ] **C1.4** `http://www.nilovcatering.ru/` и `https://www.nilovcatering.ru/` → 301 на apex
- [ ] **C1.5** 200 сохраняется на всех ключевых URL (`/`, `/about`, `/offer`, `/privacy`, `/terms`, `/menu`, `/api/lead.php` → 405)

### Блок 2. Карта без рекламы конкурентов
- [ ] **C2.1** В live-HTML главной **нет** строки `yandex.ru/map-widget/v1` (grep = 0)
- [ ] **C2.2** В live-HTML **нет** обращений к `yandex.ru/ads/` (grep = 0)
- [ ] **C2.3** Блок «КАК НАС НАЙТИ» показывает карту с меткой адреса (визуально подтверждено)
- [ ] **C2.4** Кнопка «открыть в Яндекс.Картах» ведёт на корректные координаты/адрес
- [ ] **C2.5** `title`/`aria-label` карты содержат **актуальный** адрес (Полевая Сабировская, 45, к 1), не «Большая Морская, 18»

### Блок 3. Бесплатное SEO-продвижение (делается кодом/артефактами, не в чужих ЛК)
- [ ] **C3.1** Bing/Google verification-файлы живы (уже есть — защита от потери)
- [ ] **C3.2** Расширенные structured data: `Service`, `Offer`, `AggregateRating`-совместимые поля, `GeoCoordinates`, `sameAs` — проходит валидацию schema.org
- [ ] **C3.3** Новые посадочные страницы под коммерческие запросы (в sitemap, с уникальными title/description/H1)
- [ ] **C3.4** `geo-sitemap.xml` корректен и содержит адрес/координаты
- [ ] **C3.5** Готовые «пакеты» для владельца: тексты карточек Яндекс.Бизнес / 2ГИС / Zoon / VK / Авито, готовые файлы верификации — в `docs/`
- [ ] **C3.6** Core Web Vitals не деградировали (Lighthouse Perf ≥ предыдущего уровня)

### Блок 4. Защита от регрессий
- [ ] **C4.1** `bun run lint` чисто
- [ ] **C4.2** `bun run typecheck` чисто
- [ ] **C4.3** `bun run build` собирает `out/` без ошибок
- [ ] **C4.4** Визуальная проверка: нет горизонтального переполнения на 390px
- [ ] **C4.5** Независимый критик (другая модель, без знания правок) не находит BLOCKER/HIGH
- [ ] **C4.6** Деплой выполнен, live-проверка C1/C2/C3 по HTTP зелёная

## 2. Порядок работы (волны субагентов)

**Волна 0 (разведка, параллельно).** Поиск решений по вебу: как на SpaceWeb
(nginx-фронт + Apache) корректно делать http→https без цикла; что именно
триггерит предупреждение ВК в 2026; альтертивы Яндекс-map-widget; бесплатные
каналы продвижения, доступные агенту.

**Волна 1 (пишущий код, параллельно, disjoint-файлы).**
- A: `.htaccess` — редирект + security-заголовки (+ probe для проверки среды Apache)
- B: карта — замена `map-widget` на `static-maps` + правка адреса в `contact.tsx`/`media.ts`
- C: structured data + посадочные страницы + geo-sitemap

**Волна 2 (критики, слепые, параллельно).** Каждый — свой угол: безопасность
редиректов, SEO-корректность, визуал/адаптив.

**Волна 3 (фикс находок + гейт).** Линт/типы/сборка, коммит, пуш, деплой.

**Волна 4 (критик выполнимости).** Проходит C1–C4 по факту live-сайта.

## 3. Что НЕ делает агент (только владелец в своих аккаунтах)

Яндекс Вебмастер (подтверждение прав, региональность, переобход), Яндекс
Бизнес/карточка + синяя галочка, 2ГИС, Zoon, Yell, VK-сообщество и его
верификация, Авито, обращение в поддержку ВК за снятие из «чёрного списка»,
отзывы, оплата anything.
→ Всё это агент готовит как **готовые пакеты** (C3.5), а не выполняет.

## 4. Жёсткие ограничения

- Только бесплатные методы; никаких платных сервисов.
- `output: "export"` — статика; серверный redirect на уровне приложения
  невозможен, всё через `.htaccess` и мета-теги.
- Не ломать: `/api/*.php` (POST-only эндпоинты), админку, `server-data/`,
  `config/secrets.php` (исключены из rsync).
- Деплой только через `git push` в `main` (Actions). SSH недоступен.
