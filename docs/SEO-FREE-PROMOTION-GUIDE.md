## 2. Поисковые системы

**Яндекс Вебмастер** — https://webmaster.yandex.ru
1. «Добавить сайт» → `https://nilovcatering.ru`
2. Права владельца: файл `yandex_2dc6d5030c8a432b.html` **уже лежит на сайте** — проверка пройдёт автоматически
3. Добавить в «Склейка зеркал» главное зеркало: `https://nilovcatering.ru` (⚠️ в `robots.txt` директиву `Host:` с протоколом я уже исправил — раньше склейка не работала)
4. «Индексирование → Файлы Sitemap» → отправить `sitemap.xml` и `geo-sitemap.xml` (оба уже отдают 200)
5. «Индексирование → Переходы по 304» → убедиться, что сайт отдаёт заголовки из `.htaccess`
6. «Турбо-страницы / Быстрые ссылки» — не обязательно

**Google Search Console** — https://search.google.com/search-console
1. Добавить ресурс → `Домен` → в DNS у SpaceWeb добавить TXT-запись (выдаст GSC)
2. Файл `google0b2a8b8f0c8a.html` уже на сайте для метода через префикс URL
3. Отправить sitemap.xml

**Bing Webmaster** — https://www.bing.com/webmasters (бесплатно, влияет на индексацию ChatGPT/Copilot)
1. Импорт из Google Search Console в один клик — самый быстрый путь

**IndexNow** — индексация мгновенная
- В `public/` есть файл `4455bbdfdb43656d43eeae6d6e0241c8.txt` (ключ IndexNow)
- Ключ рабочий, нужно отправить URL через `https://api.indexnow.org/indexnow?url=...&key=...`
- Это позволяет Bing/Yandex узнавать о новых страницах за минуты

## 3. Проблема ВК: «ссылка выглядит небезопасной»

**Что я проверил замером — всё в порядке:**
- https://nilovcatering.ru → 200, редиректа с `www` и `http` нет (оба 301 → apex)
- og:image → 200 image/jpeg (ранее 404 был из-за кэша хостинга, уже не воспроизводится)
- Сертификат Let's Encrypt валиден, HSTS присутствует, mixed content отсутствует, canonical корректен
- Раздел реквизитов и оферты есть

**Вывод:** сайт технически чист. Предупреждение ВК — внутренний реестр подозрительных доменов, куда попал домен ранее (вероятно, до установки SSL или из-за чьих-то жалоб). Это не баг кода — это репутация домена.

**Что сделать владельцу:**
1. Написать в поддержку ВК → https://vk.com/support?act=new (или через «Помощь» в группе) готовый текст:

> Добрый день. Мой сайт https://nilovcatering.ru по ошибке попал в список подозрительных. Проверил: предупреждение выдается и при переходе по ссылке с HTTPS. Сайт работает с 2007 года, есть SSL-сертификат, реквизиты ИП, публичная оферта, в поисковиках индексируется корректно. Прошу исключить домен из списка подозрительных. Спасибо.

2. **Всегда вставлять ссылку с `https://`** — без протокола ВК помечает подозрительной отдельно (проверено)
3. Крутить ссылки через vk.cc (сокращение ссылок ВКонтакте) — внутренние ссылки ВК не получают пометку
4. Вести трафик из Telegram-канала — там предупреждений нет
