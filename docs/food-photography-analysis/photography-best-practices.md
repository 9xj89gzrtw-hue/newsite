## 1. Strategic Overview

### 1.1 The Role of Photography in Catering Marketing

**Photography is THE most important visual asset** for catering companies because:

1. **Products are perishable** - Clients can't "try before they buy"
2. **Experience is intangible** - Photos must convey taste, service, atmosphere
3. **Trust requirement** - High-stakes purchase (weddings, corporate events)
4. **Emotional decision** - Food and celebration evoke strong feelings
5. **Competitive differentiation** - Visual quality signals quality of service

### 1.2 Photography ROI Metrics

| Investment Level | Expected Outcome | Time to ROI |
|------------------|------------------|-------------|
| Basic ($500-1500) | Adequate social presence | 3-6 months |
| Professional ($3000-8000) | Competitive website | 6-12 months |
| Premium ($10000+) | Industry leadership | 12-24 months |

### 1.3 Image Usage Strategy

**Primary Uses:**
- Website hero/slider images
- Gallery/portfolio pages
- Service-specific pages
- Social media content
- Proposals and pitch decks
- Print materials (menus, brochures)

**Secondary Uses:**
- Email marketing
- Online advertising
- Press releases
- Award submissions
- Internal training materials

### 2.4 Food Preparation Coordination

**Communication with Kitchen Team:**

1. **Menu Selection for Shoot**
   - Choose photogenic dishes from each category
   - Include seasonal specialties
   - Represent price range variety
   - Consider dietary option visibility

2. **Timing Protocol**
   - Prep extra portions (minimum 2x needed)
   - Hot foods shoot first (they wait for no one)
   - Cold items can be held longer
   - Have refresh station ready

3. **Quality Standards**
   - Perfect produce selection
   - Precise cooking times
   - Garnish prepared and ready
   - Plating consistency across multiples

## 3. Food Photography Best Practices

### 3.1 The 10 Commandments of Food Photography

1. **LIGHT IS EVERYTHING**
   - Natural light preferred when possible
   - Avoid overhead fluorescent at all costs
   - Soft, diffused light creates appetite appeal
   - Directional light adds dimension

2. **STYLE WITH INTENTION**
   - Every element should serve the composition
   - Remove distractions ruthlessly
   - Build layers from back to front
   - Create visual flow through the frame

3. **SHOW FRESHNESS**
   - Spritz with water/oil for sheen
   - Shoot immediately after plating
   - Melted ice = failed shot
   - Wilted garnish = unprofessional

4. **CONTEXT MATTERS**
   - Environment tells part of story
   - Props support, don't compete
   - Background complements subject
   - Style matches brand identity

5. **ANGLE FOR IMPACT**
   - Overhead shows pattern/design
   - 45° is natural eating view
   - Eye-level creates drama
   - Match angle to food type

6. **COLOR HARMONY**
   - Use color wheel for combinations
   - Complementary colors pop
   - Analogous colors soothe
   - Neutral backgrounds let food shine

7. **TEXTURE TELLS STORY**
   - Show crispness, creaminess, crunch
   - Side lighting reveals texture
   - Macro shots capture detail
   - Contrast smooth with rough

8. **SCALE PROVIDES REFERENCE**
   - Include familiar objects for size
   - Utensils, hands provide scale
   - Don't mislead with perspective
   - Consistent sizing across gallery

9. **MOVEMENT ADDS LIFE**
   - Pouring, sprinkling, cutting action
   - Motion blur when appropriate
   - Steam rising from hot food
   - Dynamic over static when possible

10. **HONESTY BUILDS TRUTH**
    - Photograph what you actually serve
    - Minimal acceptable post manipulation
    - Over-promising disappoints
    - Authenticity builds long-term trust

### 3.2 Composition Formulas

**Formula A: The Classic Triangle**
```
        [Garnish]
           /   \
          /     \
         /       \
[Utensil]-----[Dish]
```
- Main dish at base point
- Supporting elements at other points
- Creates stable, pleasing composition

**Formula B: The Leading Line**
```
[Background] =======> [Main Subject] ==> [Foreground]
```
- Utensil or sauce trail leads eye
- Ends at focal point
- Creates depth and movement

**Formula C: The Frame Within Frame**
```
+---------------------------+
|  [Negative Space]         |
|    +---------------+      |
|    |  [Subject]    |      |
|    +---------------+      |
|  [Context Element]        |
+---------------------------+
```
- Natural frame from props/vessels
- Isolates and emphasizes subject
- Adds sophistication

**Formula D: Rule of Thirds Grid**
```
+---------------------------+
|           |           |   |
|     X     |     X     |   |
|           |           |   |
|-----------+-----------|---|
|           |           |   |
|     X     |  [FOOD]   |   |
|           |     X     |   |
|-----------+-----------|---|
|           |           |   |
|     X     |     X     |   |
|           |           |   |
+---------------------------+
```
- Place main subject at intersection
- Balance with secondary elements
- Most universally appealing composition

### 3.3 Lighting Setups by Food Type

**Setup 1: Bright & Fresh (Salads, Appetizers, Fruit)**
```
        [Large Softbox]
              |
              |  45° angle
              V
    +-------------------+
    |                   |
    |    [FOOD]         |
    |                   |
    +-------------------+
              ^
              |
       [White Reflector]
```
- Key: Large softbox camera left
- Fill: White reflector camera right
- Background: Clean white or light gray
- Effect: Fresh, healthy, vibrant

**Setup 2: Warm & Cozy (Comfort Food, Soups, Baked Goods)**
```
[Smaller Softbox]    [Warming Gel]
       \               /
        \             /
         \           /
          \         /
    +-------------------+
    |    [FOOD]         |
    +-------------------+
            |
    [Gold Reflector]
```
- Key: Softer, warmer light source
- Color: Slight warm cast (golden hour feel)
- Background: Wood, warm tones
- Effect: Comforting, indulgent, homey

**Setup 3: Dramatic & Premium (Steaks, Seafood, Fine Dining)**
```
[Spot/Grid]        [Rim Light]
     \                /
      \              /
       \            /
        \          /
    +-------------------+
    |    [FOOD]         |
    +-------------------+
```
- Key: Focused, directional light
- Rim: Edge separation light
- Background: Dark, minimal
- Effect: Premium, dramatic, luxurious

## 4. Event Photography Best Practices

### 4.1 Pre-Event Preparation

**Week Before:**
- [ ] Review event timeline with client
- [ ] Confirm photography permissions
- [ ] Scout venue if possible
- [ ] Prepare equipment checklist
- [ ] Charge all batteries
- [ ] Format memory cards
- [ ] Check weather (outdoor events)

**Day Before:**
- [ ] Final equipment check
- [ ] Pack backup gear
- [ ] Review shot list
- [ ] Plan arrival time (early!)
- [ ] Charge phone/portable batteries
- [ ] Get good rest

**Day Of - Arrival:**
- [ ] Arrive 1-2 hours before guests
- [ ] Scout lighting conditions
- [ ] Identify key locations
- [ ] Test shots in each area
- [ ] Meet with event coordinator
- [ ] Confirm schedule changes

### 4.2 During Event Workflow

**Phase 1: Setup & Details (Before Guests)**
Priority: Capture everything pristine
- Empty room establishing shots
- Each table setting detail
- Food stations fully dressed
- Floral arrangements
- Signage/place cards
- Lighting ambiance
- Vendor setups

**Phase 2: Guest Arrival**
Priority: Energy and first impressions
- Entrance/arrival moments
- Cocktail hour service
- Guest interactions
- Venue coming alive
- Initial atmosphere

**Phase 3: Main Program**
Priority: Key moments, don't miss
- Speeches/toasts
- First dance (weddings)
- Cake cutting
- Awards presentations
- Entertainment highlights
- Guest reactions

**Phase 4: Dining Service**
Priority: Food in context
- Service in action
- Guest enjoyment
- Food close-ups (if appropriate)
- Table atmosphere
- Staff professionalism

**Phase 5: Party/Dancing**
Priority: Energy and celebration
- Dance floor action
- Candid moments
- Late-night snacks
- Celebration peak energy
- Closing shots

## 5. Technical Standards

### 5.1 Camera Settings Quick Reference

| Situation | Mode | Aperture | Shutter | ISO | Focus |
|-----------|------|----------|---------|-----|-------|
| Food studio | Manual | f/4-f/8 | 1/125 | 100 | Manual single |
| Food natural light | Aperture | f/2.8-f/4 | Auto | 400-800 | Single point |
| Event wide | Aperture | f/5.6-f/8 | 1/60+ | 800-3200 | Zone/AI servo |
| Event detail | Manual | f/2.8-f/4 | 1/200+ | 1600-6400 | Single point |
| Action/service | Shutter priority | Auto | 1/250+ | Auto | Continuous |
| Low light | Manual | f/1.4-f/2.8 | 1/100+ | 3200-12800 | AI servo |

## 6. Post-Production Workflow

### 6.1 Software Recommendations

**Professional:**
- Adobe Lightroom Classic (catalog management + editing)
- Adobe Photoshop (advanced retouching)
- Capture One (alternative RAW processor)

**Efficient Alternatives:**
- Luminar Neo (AI-powered)
- DxPhotoLab (noise reduction leader)
- Darktable (free, open source)

### 6.2 Editing Workflow Steps

**Step 1: Import & Organize**
- Import RAW files to catalog
- Apply metadata presets (copyright, keywords)
- Initial rating (1-5 stars)
- Reject obvious failures

**Step 2: Culling**
- Pass 1: Quick review, reject clearly bad
- Pass 2: Rate selects (3+ stars)
- Pass 3: Identify heroes (5 stars)
- Pass 4: Final selection for delivery

**Step 3: Base Corrections**
- White balance adjustment
- Exposure correction
- Lens profile corrections
- Basic tone curve
- Crop/straighten as needed

**Step 4: Selective Edits**
- Local adjustments (brushes, gradients)
- Spot healing (dust, minor blemishes)
- Noise reduction (high ISO images)
- Selective sharpening

**Step 5: Style Application**
- Preset application (developed brand look)
- Color grading adjustments
- Final contrast/clarity tweaks
- Vignette decisions

**Step 6: Export**
- Select export preset for use case
- Batch process final selections
- Verify output quality
- Organize exported files

### 6.3 Retouching Ethics

**Acceptable:**
- ✅ Exposure correction
- ✅ White balance adjustment
- ✅ Color enhancement (within reason)
- ✅ Dust spot removal
- ✅ Minor blemish removal (on surfaces, not people)
- ✅ Cropping/straightening
- ✅ Noise reduction
- ✅ Sharpening for output

**Questionable:**
- ⚠️ Heavy skin smoothing (people)
- ⚠️ Body alteration (people)
- ⚠️ Significant color changes
- ⚠️ Adding/removing elements
- ⚠️ Composite creation

**Unacceptable:**
- ❌ Misrepresenting portion sizes
- ❌ Adding items not served
- ❌ Removing negative elements deceptively
- ❌ Creating impossible scenarios
- ❌ False advertising implications

## 7. Website Integration

### 7.1 Image Specifications by Use Case

**Hero/Slider Images:**
```
Recommended: 1920 x 1080 px (16:9)
Minimum: 1400 x 788 px
Format: JPEG (85% quality) or WebP
```

**Gallery Thumbnails:**
```
Recommended: 600 x 400 px (3:2)
Minimum: 400 x 267 px

File size: < 80KB
Aspect ratio: Consistent within gallery
```

**Gallery Full-Size (Lightbox):**
```
Recommended: 1200 x 800 px
Maximum: 2000 x 1333 px
Format: JPEG (85% quality)
File size: < 500KB
Allow: Zoom on click
```

**Social Media Sharing (OG Images):**
```
Facebook: 1200 x 630 px
Twitter: 1200 x 675 px
LinkedIn: 1200 x 627 px
Pinterest: 1000 x 1500 px (vertical)
Instagram Feed: 1080 x 1080 px
```

### 7.2 Alt Text Guidelines

**Good Alt Text Examples:**

```html
<!-- Specific and descriptive -->
<img src="wedding-buffet.jpg" alt="Elegant wedding buffet display featuring 
grilled salmon station, artisan cheese board, and seasonal vegetable 
arrangement at lakeside venue">

<!-- Concise but informative -->
<img src="beef-tenderloin.jpg" alt="Close-up of medium-rare beef tenderloin 
with red wine reduction, served on white plate with roasted vegetables">

<!-- Context-appropriate -->
<img src="corporate-event.jpg" alt="Corporate holiday party catering setup 
for 200 guests featuring themed food stations and cocktail service">
```

**Bad Alt Text Examples:**
```html
<!-- Too vague -->
<img src="food.jpg" alt="food">

<!-- Keyword stuffing -->
<img src="buffet.jpg" alt="catering buffet food wedding corporate event 
party best catering service affordable luxury food display professional">

<!-- Missing context -->
<img src="event.jpg" alt="photo">
```

## 8. Legal & Ethical Considerations

### 8.1 Model Releases

**When Required:**
- Recognizable individuals in promotional use
- Stock/commercial usage intent
- Long-term archive plans
- Minor children (always require parent consent)

**Template Elements:**
- Full legal name of subject
- Description of photos taken
- Permitted uses (scope)
- Compensation (if any)
- Rights duration
- Signature date

### 8.2 Property Releases

**When Needed:**
- Private venues (not public spaces)
- Art installations
- Distinctive interior designs
- Branded products prominently featured

### 8.3 Music & Copyright

**Event Photography Often Includes:**
- Played music (background, live performance)
- Artwork on walls
- Logos and branding
- Trademarked products

**Best Practice:**
- Document what's included
- Understand fair use limitations
- When in doubt, consult attorney
- Consider restricted usage for sensitive content

### 8.4 Privacy Best Practices

**For Catering Websites:**
- Focus on food and decor over faces
- Use shallow DOF to soften background faces
- Prefer back/side profiles when showing guests
- Obtain written permission for any recognizable person
- Be especially careful with children
- Respect event photo policies

## 10. Vendor Selection Guide

### 10.1 Evaluating Portfolio

**Red Flags:**
❌ No food photography experience
❌ Inconsistent style across portfolio
❌ Over-edited/unrealistic looking food
❌ Poor low-light examples (for event work)
❌ No commercial/catering clients shown
❌ Can't explain their process

**Green Flags:**
✅ Diverse food photography samples
✅ Consistent quality and style
✅ Natural-looking appetizing food
✅ Strong event/low-light work
✅ Relevant catering/restaurant clients
✅ Clear professional process
✅ Good communication/responsiveness

### 10.2 Questions to Ask

**Experience:**
1. How many food/event shoots have you done?
2. What types of cuisine have you photographed?
3. Do you have experience with our type of events?
4. Can you share references from similar clients?

**Process:**
5. What does your typical workflow look like?
6. How do you handle challenging lighting?
7. What is your turnaround time?
8. How many final images should we expect?
9. What is your revision policy?

**Business:**
10. What are your rates and what's included?
11. What are the payment terms?
12. Who owns the final images?
13. Can we get raw files (usually no, but ask)?
14. What happens if you're unavailable for our event?

### 10.3 Contract Essentials

**Must Include:**
- Scope of work (dates, deliverables)
- Usage rights (where/how images can be used)
- Payment terms (schedule, method)
- Cancellation policy
- Rescheduling provisions
- Image licensing specifics
- Model release responsibilities
- Timeline for delivery
- Revision limits
- Liability/insurance clauses

### Emergency Troubleshooting
```
┌─────────────────────────────────────────────┐
│           TROUBLESHOOTING GUIDE              │
├─────────────────────────────────────────────┤
│ Image blurry? → Faster shutter, stabilize   │
│ Too dark? → Open aperture, raise ISO        │
│ Too bright? → Close aperture, faster shutter │

│ Noisy/grainy? → Lower ISO, post-process NR  │

│ Food looks dull? → Oil spritz, freshen      │
│ Colors off? → Shoot RAW, adjust later       │

```
