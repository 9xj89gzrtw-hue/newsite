## B. ЧТО МОГУ СДЕЛАТЬ Я (код/хостинг/деплой)

1. **VK-предупреждение** — диагностировать реальную причину, исправить всё,
   что лежит в коде, `.htaccess`, OG-превью, отдать владельцу готовую
   заявку на перепроверку домена.
2. **Lighthouse SEO-аудит** — локальный прогон, починка находок.
3. **Schema.org** — расширить JSON-LD: `WebSite` (SearchAction),
   `BreadcrumbList`, `SiteNavigationElement`, `Service`, `Review`,
   `MenuItem`, `AggregateRating`, `Question/Answer` уже есть.
4. **robots.txt / yandex.txt / llms.txt** — проверить актуальность состава ботов.
5. **Core Web Vitals** — реальные замеры, починка узких мест.
6. **Шаблоны для владельца** — готовые тексты заявок в справочники.

## D. ПЛАН РАБОТ (несколько волн, субагенты параллельно)

**Волна 1 — диагностика (параллельно, 4 субагента)**
- W1.1 «ТехSEO-аудит»: прод + структура HTML + мета + изображения → отчёт.
- W1.2 «VK-rootcause»: почему ВК считает ссылку небезопасной → механизм + фиксы.
- W1.3 «Справочники»: бесплатные площадки СПб для кейтеринга → список с URL, регистрация, требования.
- W1.4 «CWV»: замеры LCP/CLS/INP + точки роста → числа.

**Волна 2 — правки кода (после диагностики)**
- W2.1 Schema.org расширение.
- W2.2 VK-фиксы (OG/`.htaccess`/иная причина).
- W2.3 Починка находок техSEO.
- W2.4 Починка CWV.

**Волна 3 — шаблоны + верификация**
- W3.1 Готовые тексты заявок для владельца.
- W3.2 Полная проверка + CI + деплой.
