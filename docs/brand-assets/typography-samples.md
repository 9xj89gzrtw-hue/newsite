## Recommendations for New Catering Brand

### For Luxury/High-End Positioning:
1. **Font:** Serif or elegant sans-serif (Playfair Display, Montserrat)
2. **Weight:** Light to Regular (300-400)
3. **Case:** UPPERCASE or Title Case
4. **Spacing:** Wide letter-spacing (tracking +50 to +100)

### For Modern/Trendy Positioning:
1. **Font:** Geometric sans-serif (Poppins, Futura-style)
2. **Weight:** Medium to Bold (500-700)
3. **Case:** lowercase or UPPERCASE
4. **Spacing:** Normal to slightly tight

### For Casual/Family-Style:
1. **Font:** Friendly rounded sans-serif (Nunito, Quicksand)
2. **Weight:** Bold (700)
3. **Case:** Title Case or Mixed Case
4. **Spacing:** Normal

### For Boutique/Specialty:
1. **Font:** Custom script or distinctive display font
2. **Weight:** Variable for contrast
3. **Case:** Artistic mixing
4. **Spacing:** Custom/optical kerning recommended

## Accessibility Considerations

### Minimum Font Sizes
- **Logo primary text:** Never below 16px digital / 10mm print
- **Tagline/supporting:** Never below 12px digital / 6mm print
- **Contrast ratio:** 4.5:1 minimum for normal text

### Legibility Tips
- Avoid decorative fonts for essential information
- Ensure logos work at small sizes (favicon scale)
- Test grayscale conversion for logo viability
- Maintain clear hierarchy between elements
