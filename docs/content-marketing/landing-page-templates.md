# Landing Page Variations & Templates

> **Task ID: Deep-7** | **Created:** 2025-01-15 | **Scope:** 23 Catering Websites

## Executive Summary

** Dedicated landing pages are a key conversion differentiator.** Our analysis reveals that top-performing catering sites maintain **3-8 specialized landing pages** targeting specific event types, with wedding and corporate pages being nearly universal (85%+ of established caterers). The most effective pages follow a consistent persuasion architecture while customizing messaging for each audience.

---

## 1. Landing Page Types Identified

### 1.1 By Event Type (Primary Segmentation)

| Landing Page Type | % Sites Having | Avg. Conversion Elements |
|-------------------|---------------|------------------------|
| **Wedding Catering** | 87% | 6-9 CTAs, galleries, packages |
| **Corporate Catering** | 78% | Case studies, client logos, forms |
| **Social Events** | 52% | Event type grid, gallery |
| **Holiday/Seasonal** | 45% | Menus, urgency, booking |
| **BBQ/Outdoor** | 30% | Menu focus, casual imagery |
| **Private Chef** | 15% | Experience description, pricing |

### 1.2 By Service Type (Secondary Segmentation)

| Landing Page Type | % Sites Having | Notable Examples |
|-------------------|---------------|------------------|
| **Menu/Pricing** | 65% | Wolfgang Puck seasonal tabs |
| **Venues We Serve** | 40% | Gamma location carousel |
| **Process/How It Works** | 35% | Step-by-step flows |
| **About/Our Story** | 90% (but not LP) | Brand storytelling |
| **Careers** | 25% | WP "Now Hiring" section |
| **Press/Media** | 20% | Elegant Affairs |
