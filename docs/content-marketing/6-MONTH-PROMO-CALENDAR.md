# 6-Month Promotional Calendar Template

> **Purpose:** Ready-to-use promotional planning template for Interfood catering
> **Based on:** Analysis of seasonal campaigns from 23 catering websites
> **Adaptable for:** Any starting month - adjust seasons accordingly

---

## Calendar Overview

### How to Use This Template

1. **Identify your start month** and align seasons accordingly
2. **Customize promotions** for your market, capacity, and goals
3. **Assign owners** to each campaign element
4. **Build in buffer time** (promotions need 2-4 weeks prep)
5. **Track results** and adjust future calendars based on data

### Campaign Naming Convention

```
Format: [YEAR]-[MONTH]-[CAMPAIGN-TYPE]-[THEME]
Example: 2025-03-WEDDING-SPRING-KICKOFF
```
