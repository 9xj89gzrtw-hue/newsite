# Content Gap Analysis

> **Task ID: Deep-7** | **Created:** 2025-01-15 | **Scope:** 23 Catering Websites

## Executive Summary

This analysis identifies **content that most top-tier catering sites have**, **what's unique/differentiating**, and **opportunities for competitive advantage through content**. Key finding: **65% of analyzed sites are underinvesting in content marketing**, creating significant opportunity for those who execute well.

## 5. Content Quality Standards

### 5.1 Photography Standards (Based on Top Sites)

| Element | Standard | Source Reference |
|---------|----------|------------------|
| **Hero images** | Minimum 1920x1080, professional lighting | WP, CEP |
| **Gallery images** | Consistent editing style, 10-20 minimum | All top sites |
| **Food photography** | Styled shots, appetizing, detail shots | Tall Guy, Concorde |
| **Event coverage** | Wide + detail shots, guest reactions | By Word of Mouth |
| **Team photos** | Professional, approachable, consistent | Gamma, JDK |

### 5.2 Copy Standards

| Element | Standard |
|---------|----------|
| **Tone** | Warm, professional, confident |
| **Voice** | Expert but accessible |
| **Headline length** | 6-10 words optimal |
| **Paragraphs** | Max 3-4 lines (web scanning) |
| **CTA clarity** | Action-oriented, specific benefit |
| **Proofreading** | Error-free (critical for premium positioning) |

### 5.3 Technical Standards

| Element | Standard |
|---------|----------|
| **Page load speed** | <3 seconds |
| **Mobile optimization** | Fully responsive |
| **Image optimization** | WebP with fallbacks, lazy loading |
| **Schema markup** | LocalBusiness, Event, FAQ |
| **Accessibility** | WCAG 2.1 AA compliance |
| **SSL** | HTTPS everywhere |
